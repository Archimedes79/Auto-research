**What it does**: an online multi-view detector that carries a FIFO queue of N = 4 frames x K = 256 top-scoring object queries (context embedding, 3D centre, velocity, ego pose, time interval). Stored centres are moved into the current frame with the relative ego transform; the aligned queries enter the decoder by cross-attention with the image tokens. A motion-aware LayerNorm (MLN) maps [relative ego transform, velocity, dt] by two linear layers to a scale and shift applied as gamma * LN(x) + beta to the stored embeddings (an implicit motion compensation).

**Results that matter** (nuScenes val, R50 256 x 704): 0.432 mAP / 0.540 NDS at 27.1 FPS against SOLOFusion 0.427 / 0.534 at 11.4 FPS; light version 0.450 / 0.550 at 31.7 FPS; full model test 67.6 NDS. Memory length (mAP / NDS / mAVE): 0 frames 0.317 / 0.372 / 0.885, 1 frame 0.394 / 0.501 / 0.324, 2 frames 0.401 / 0.505 / 0.314, 4 frames 0.402 / 0.505 / 0.316 (27.1 FPS against 27.7 without memory). MLN ablation: explicit motion compensation alone (shifting the stored object by its velocity) did not help (mAP 0.380, NDS 0.481); implicit ego-pose encoding +2.0 mAP; time and velocity inputs +0.4 mAP each.

**Transferable technique**: (1) the temporal state is a small set of originals (centre + velocity + time) moved by exact coordinate transforms, never a resampled map: the same conclusion as our chain-the-coordinates finding, and the cost is flat in the history length. (2) Gains saturate at 1-2 frames of object memory. (3) Feeding [ego transform, velocity, dt] as a conditioning vector (FiLM-like) beat hand-shifting the state: a candidate for our dt-conditioned object head (plan 8.3).

**Cost and fit**: negligible temporal cost per the paper; but it needs a query detector and cross-attention, not a dense 0.5 m grid with lines and areas.

**Doubts**: the page's own query counts are inconsistent (text vs footnote); detection only; the paper argues dense BEV memories misalign moving objects but gives no matched dense-BEV experiment of its own (the SOLOFusion row is a different model and training).
