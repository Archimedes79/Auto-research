**What it does**: A depth net predicts a discrete depth distribution D per view; the expanded map is the outer product F = D (x) X (V x H x W x D x C), never materialised. A 3D query at (x, y, z) gets a view reference point (u, v, d = z_cam) from the intrinsics, offsets and attention weights come from the query, and the sampler is trilinear over (u, v, d). The trilinear step splits into (1) linear interpolation of the depth distribution, W = w_0 (1 - t_d) + w_1 t_d at the point's own depth, and (2) a depth-weighted bilinear interpolation of X. This is "pull with depth weight" with learned offsets, fused into one CUDA kernel. Naively pre-weighting the features and using 2D deformable attention fails because neighbouring samples share features but need different depth scores (appendix B).

**Results that matter** (nuScenes val, detection): BEVFormer-base 41.6 / 51.7 -> 43.0 / 53.1 mAP / NDS; small 37.0 / 47.9 -> 40.1 / 50.1; tiny 25.2 / 35.4 -> 26.9 / 37.3; DETR3D 34.7 / 42.2 -> 35.5 / 42.8. One-layer lift comparison: point attention 35.0 / 42.2, Lift-Splat 36.9 / 43.0, DFA3D 37.3 / 43.6. Depth source: unsupervised depth 41.7 / 51.8, supervised 43.0 / 53.1, lidar ground-truth depth 56.7 / 62.4. Cost of the equivalent implementation vs a naive volume: about 29 MB and 5.2 ms vs 3204 MB and 161.9 ms (GPU not named for this timing); BEVFormer 2.8 -> 2.4 FPS, 6.9 -> 7.0 GB. No map segmentation.

**Transferable technique**: (1) the exact decomposition: depth score by linear interpolation along the bin axis, then weighted bilinear gather, with no frustum tensor (gives our test "uniform depth equals P / D" and "one-hot depth keeps only the voxels at that depth"); (2) the large oracle gain (+15 mAP with lidar depth) is the argument for a depth-oracle test of the lift.

**Cost and fit**: attention-based, mmcv CUDA kernel, slower than the baseline end to end (2.4 FPS); the idea ports without attention (fixed reference points, no offsets).

**Doubts**: learned deformable sampling matters more than the depth axis alone (trilinear only: 40.6 / 51.3 vs 43.0 / 53.1); depth gains are modest (+1.4 mAP average) when depth is monocular-estimated; non-commercial licence; no segmentation, no far-range analysis.
