**What it does**: Input is a single-frame 4D radar tensor R x A x E x D = 256 x 107 x 37 x 64 (K-Radar). Doppler bins become an 8-channel descriptor per cell (top-3 powers, their indices, mean, std). Sidelobe-aware sparsification keeps the top N_r = 250 cells per range bin (ranked by Doppler-mean power) instead of a global threshold. Range-wise self-attention (2 layers, 32-dim, 4 heads) runs inside each range bin; sparse convolutions + 3D deformable self-attention run in spherical voxel space (feature volume 64 x 27 x 10 x 192). Learnable Cartesian queries (14 x 128 x 128) are projected to spherical reference points and gather features by deformable cross-attention (the paper states it avoids explicit interpolation). A 3D ResNet-18 + FPN decodes to a 128 x 128 x 14 grid at 0.4 m, classes free / background / foreground.

**Supervision**: cross-entropy + Lovasz-softmax + scene-class affinity losses (geometric and semantic), loss-normalised. 24 annotated sequences, 11,333 / 1,059 / 2,878 frames.

**Results that matter** (IoU at 12.8 / 25.6 / 51.2 m): full 48.8 / 39.1 / 30.4; without spherical feature encoding 46.2 / 38.4 / 29.4 (foreground IoU 20.7 / 18.7 / 15.8 vs 15.4 / 15.5 / 13.9); without sidelobe-aware sparsification mIoU drops to 24.1 / 20.2 / 15.6 from 34.3 / 28.5 / 22.6. 302.9 ms per frame (3.3 fps) on one GTX 3090, 133.9 ms (7.46 fps) for the lightweight variant.

**Transferable technique**: (1) keep the radar in its own polar frame until the last step: the ablation shows +2 to +3 IoU and +5 foreground IoU at close range; (2) rank returns per range bin, not globally, because sidelobe / near-range power dominates a global threshold (mIoU 34.3 to 24.1 when removed).

**Cost and fit**: far outside our budget (300 ms). The raw 4D tensor and K-Radar are not our data; nuScenes radar is a 2D+1D detection list.

**Doubts**: deformable-attention aggregation is not an interpolation-free proof; one dataset (K-Radar), well-conditioned sequences only; sidelobe gain is shown by removal, not against a global-threshold baseline of equal budget.
