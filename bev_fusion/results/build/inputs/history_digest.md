# bev_fusion: history digest of all experiments (read-only digest, written 2026-11-02)

Scope: the 23 folders of `bev_fusion/experiments/` (the brief said 22; the list in the brief has 23 names), in date order of the card start. Numbers are copied verbatim from the cards, reports and result files named in the last column; nothing was recomputed or re-rounded. "VAL" = nuScenes val scenes (82 of the 150 on disk; parts 1-6 downloaded), "cold" = every frame from an empty memory, "1 seed" = one training seed. The TEST split was never used by any BEV experiment (cards state it). GT labels: v5 = autogt signature `15efbde2d1`; v8 = store `c643a7539d` (trainer cache key `0.5_4_6a7aa7864a`, the v9 code makes the same GT); older runs carry other signatures (see Caveats).

Sources read: all `experiment.md` files (t1_r4_soa has none: its `report.md` was used), `t1_full_chain/report.md`, `t3_improve_loop/report.md`, `t6_soa_gap/report.md`, `t2_block_swaps/results/arms.md` and `calibration.md`, the result `.md/.txt` files in the experiment folders, `experiments/README.md`, `records/LEDGER.md`, `BOARD.md`, `keep3.json`, `champion.json`, `schedule.csv`, `open_findings_2026-11-02.md`, `bev_fusion/README.md`, and for the lane project `PROBLEM.md`, `closed_questions.md`, `HANDOVER.md`. One extra source outside the cards is flagged where used: the scratch comparison files `bev_fusion/temp/t7/compare2_ctl_*.txt` (the only numbers against the equal-GT control for t7; not in git, not in the card).
