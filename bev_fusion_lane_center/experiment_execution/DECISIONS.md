# Decisions

Neutral record of the decisions of this problem (rewritten on 2026-11-20 under D129; the full original texts of D1 - D128 are in the git history, folder `experiment_execution/decisions/`, and behind the tag `archive/pre-cleanup-2026-11-20`).
One row per decision. A decision counts as DECIDED when it has a row in the table `## Decided` (first cell the date, second cell starting with `D<n>:`); a question without a decided row is OPEN (table `## Open`: id, question, options, recommendation, evidence).
An agent writes the question into `## Open` and acts only on a decided row; a change of a protected file, a TEST check, a champion promotion, a change of PROBLEM.md or of the gates, and every permission (download, install, mail, shutdown, push, backup, remote) is such a decision.
The tools read this file: `guard_hook.py` (a grant names a decided `D<n>`), `commit_paths.py` (`--decision D<n>` must be decided), `testgate.py` (a TEST check by decision: the row of the id says that it grants one TEST check), `package.py` (`gt --drop ... --decision D<n>`: the row names the signatures).
A new decision gets the next free id (the highest id of BOTH tables plus one), and its row is committed at once (two writers once took the same id). New questions are appended at the END of the file, which is the Open table: a row appended there is never decided by accident.
