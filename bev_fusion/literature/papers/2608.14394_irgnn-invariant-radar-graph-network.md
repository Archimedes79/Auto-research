**What it does**: Converts RadarScenes radar points into graphs with translation- and rotation-invariant features (preprocessing follows RadarGNN), then a message-passing network with residual connections and a virtual node layer, followed by task heads for classification and box regression.

**Results that matter**: claims to beat existing radar detectors on RadarScenes and to cut inference compute and memory; mAP, latency and GPU are not on the page read.

**Transferable technique**: the virtual node (global context vector without attention) is a cheap way to give each radar point a sensor-wide context.

**Cost and fit**: unknown.

**Doubts**: the RadarGNN study found that rotation invariance hurts detection (19.6 vs 56.5 mAP with translation invariance only); whether IRGNN fixes that is unread.
