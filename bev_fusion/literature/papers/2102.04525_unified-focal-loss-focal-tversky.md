**What it does**: L_aUF = lambda L_maF + (1 - lambda) L_maFT: a modified asymmetric Focal loss (focal factor (1 - p_t)^gamma on the background only, the rare class is not suppressed) plus a modified asymmetric Focal Tversky loss (rare class (1 - mTI)^(1 - gamma), others (1 - mTI)); the Tversky index mTI = TP / (TP + delta FP-type + (1 - delta) FN-type). Recommended lambda = 0.5, delta = 0.6, gamma about 0.5 in 3D (2D tuned over 0.1-0.9). Focal Tversky (memory): FTL = sum_c (1 - TI_c)^(1/gamma), TI = TP / (TP + alpha FN + beta FP), alpha = 0.7, beta = 0.3, gamma = 4/3.

**Results that matter** (2D, DSC / IoU): DRIVE retinal vessels CE 0.789 / 0.652, Dice 0.799 / 0.666, Focal Tversky 0.798 / 0.664, Unified Focal asym 0.803 / 0.671; CVC-ClinicDB Dice 0.867 -> Unified 0.909; BUS2017 Dice 0.767 -> 0.824 (focal alone 0.603). On the thin-structure set the gain over plain Dice is +0.4 Dice points with overlapping confidence intervals.

**Transferable technique**: a recall-weighted Tversky term (delta around 0.6-0.7) is the standard knob for making a thin class FN-averse; our tolerant Dice has the same job via the dilation and could take a Tversky weighting inside `tolerant_dice_loss` (num / (num + a FP + b FN) form). Not worth a port before the distance / boundary arms.

**Cost and fit**: free; sums over the image, so class-frequency-agnostic; no soft-label correctness (same flaw as soft Dice for soft targets, see 2303.16296) and no ignore-mask discussion.

**Doubts**: original U-Net only, no nnU-Net; boundary-based losses were excluded from the comparison; gamma not tunable for multi-class (authors); the DRIVE gain is within noise.
