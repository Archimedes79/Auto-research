**What it does**: Per radar (nuScenes, up to 128 clusters, 2D position and velocity; dynamic clusters removed with the velocity) a binary BEV grid of 215 x 50 cells at 0.4 m in the radar's own frame (range 0-86 m, width +-10 m) is filled; k = 1, 10 or 20 ego-compensated frames are aggregated. A U-Net-style encoder-decoder (3x3 convolutions, skips) predicts three classes per cell: occupied / free / unobserved (targets 1.0 / 0.0 / 0.5). One network serves all five radars. Whether the grid is polar or Cartesian is not stated on the page (a metric grid in the radar frame).

**Supervision**: lidar aggregated over the whole scene in global coordinates, projected into each radar frame, point-count threshold + dilation / hole filling / erosion, ray tracing from the radar (free before the first return, occupied run, unobserved behind), concave-hull and FOV masks set to ignore. Loss: Lovasz-softmax (class-weighted CE within 0.001 after tuning). SGD, lr 0.05.

**Results that matter** (test, 20-frame aggregation, IoU occupied / free / unobserved / mean): Delta ISM 0.029 / 0.391 / 0.311 / 0.244; Gaussian ISM 0.012 / 0.444 / 0.213 / 0.223; ray trace 0.066 / 0.576 / 0.405 / 0.349; network 0.108 / 0.614 / 0.593 / 0.439. A single-frame network beats ray tracing with any number of aggregated frames; aggregation gains 12.5 % (10 frames) and 16.7 % (20) mIoU over one frame. The fixed Gaussian ISM is the worst, which is the direct evidence against a hand-set spread.

**Transferable technique**: learned replacement of the Gaussian inverse sensor model, trained on nuScenes radar with lidar rays, with an explicit "unobserved" class and ignore masks; the per-radar frame plus a shared network keeps mounting out of the model. Static aggregation over 10-20 frames helps, consistent with our radar-memory plan.

**Cost and fit**: small U-Net on 215 x 50; no runtime stated. The lidar labels need the lidar blobs (not on disk) or the keyframe sweeps.

**Doubts**: absolute occupied IoU is low (0.108); the Gaussian ISM baseline parameters are not given here; dynamic objects are discarded, which is the opposite of what a moving-target BEV needs.
