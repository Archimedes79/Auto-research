**What it does**: plain Gaussian NLL gives the mean a gradient (mu - y) / sigma^2, so cells with a large predicted variance are under-trained and the mean stalls. beta-NLL multiplies each term by stopgrad(sigma^(2 beta)): L = E[ sg(sigma^(2b)) ( 0.5 log sigma^2 + (y - mu)^2 / (2 sigma^2) ) ]. Gradients: d/dmu = (mu - y) / sigma^(2-2b); b = 0 is the NLL, b = 1 gives the MSE gradient for the mean while sigma is still learned; b = 0.5 is the recommended start. The loss value is not a quality measure (monitor NLL and RMSE).

**Results that matter** (paper tables): NYUv2 depth (AdaBins-based) RMSE / LL: NLL 0.3854 / -4.52, b = 0.5 0.3789 / -7.50, b = 1 0.3845 / -5.10, MSE 0.3776, L1 0.3850 (a small RMSE gain, a worse LL at 0.5); dynamics models RMSE 1D-Slide NLL 0.0192 -> b = 0.5 0.0064 (MSE 0.0068), Fetch-PickAndPlace 0.00163 -> 0.00096 (MSE 0.00103); UCI Concrete 6.08 -> 5.61, Yacht 3.56 -> 2.35 (MSE 0.78). NLL's RMSE is very sensitive to hyper-parameters, beta-NLL's much less. No added cost.

**Transferable technique**: add a log-variance channel to each distance field (and later velocity); L = sg(exp(beta s)) x (0.5 s + 0.5 (d - mu)^2 exp(-s)) with s = log sigma^2 clamped, weights w = the existing cell masks. Variance then reads as registration / occlusion uncertainty for the planner. Our truncated distance Huber (delta 0.5 m) can stay as a hard-cell fallback (robust variant: Huber residual in the quadratic term). Spec tests: b = 0 reproduces the closed-form Gaussian NLL; b = 1 gives the gradient of 0.5 (mu - y)^2 on mu; w = 0 cells give zero gradient; sigma clamped inside [e^-3, e^1] m^2 never NaNs.

**Cost and fit**: one channel and a few elementwise ops. Clamp the variance floor (the paper warns that without a lower bound the training distribution may never stabilise). Pairs badly with Kendall task weights if the same term is both learned-variance and learned-task-weight: keep fixed group weights for lines while the NLL is on.

**Doubts**: no segmentation / map task; the depth gain is small and the log-likelihood gets worse at b = 0.5; student-t and other likelihood families beat it on LL on some sets; evidence from MapUncertainty (2403.16439) shows a Laplace NLL on map vertices raised StreamMapNet-like regression error, so test the mean accuracy of the distance field first (arm vs Huber, same seeds).
