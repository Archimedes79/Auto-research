# studies/recipes - the scripts that made the numbers of the closed experiments

Moved here from `temp/` on 2026-11-10 (the git rule: a script that a card, report or plan names as how a number was made is kept in a code folder, not in scratch). One folder per origin, the sub-paths are the old ones (`temp/<folder>/<file>` is now `studies/recipes/<folder>/<file>`; every citation in the tree was rewritten, the run records and the ledger keep the old text). The experiments are the cards in `../../results/experiments/` (t1 - t8, t11), the plan in `../../plan/`.

What to know before running one:
- **Records, not tools.** Nothing here is scheduled or running. A script reproduces its number only with the run folders, caches and checkpoints of its time (several are gone or moved to D:), and it was not re-run at the move. The imports of every file resolve (checked 2026-11-10).
- **Run from the `bev_fusion` folder**, as before. The files were moved byte for byte; the `Run:` / `Usage:` lines in their docstrings still say `temp/<folder>/<file>`: read them as `studies/recipes/<folder>/<file>`. Their inputs and outputs (logs, caches, `*.pt`, queue files, `temp/radar/cache/mini_multisweep.pt`) stay in the scratch folder `temp/` and are not in git.
- **What was changed on the move** (nothing else): the folder depth in the scripts that find the project folder from their own location (`cd "$(dirname "$0")/../.."` and `ROOT = ... "..", ".."` got one more level: `study/lane2.sh`, `lane3.sh`, `lane4.sh`, `make_image_runs.sh`, `t5/run_v2.sh`, `t7/finish.sh`, `train/post_train.sh`, `train/run_cfg.sh`, `t4/dualbev_front_eval.py`, `t5/check_divider_records.py`, `t5/lane_probe.py`); the calls of moved files (`lane*.sh` -> `train/run_cfg.sh`, `t5/run_v2.sh` -> `lane_probe_v2.py`, `train/post_train.sh` -> `build_tables.py`); the imports of modules that D48 renamed (`flow_selfsup_long.py`, `probe_cam_lanes.py`, `sup/video_fused.py` read `studies/early/` now; `check_oracle_lift_stride16.py` also needs `tests/support`).
- Moved elsewhere instead: the three provenance scripts of the weights to `../../models/`, the scout tables to `../../literature/scout_tables/`, the review notes to `../../records/observe_2026-10-30_notes.md`, `radar_recon_test.py` (+ its result) to `../early/`.
