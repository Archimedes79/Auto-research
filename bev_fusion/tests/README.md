# tests - the gates of the blocks (plan.md section 10.1)

A gate is a test with a known answer: it checks its own pass criterion and exits with 0 (pass) or 1 (fail). No block is chained into the next before its gate passes. `run_gates.sh` runs the self-tests of the modules and the gates below, one PASS / FAIL line per block (`wsl bash tests/run_gates.sh`; with `--all` also the slow ones, minutes on the CPU). The real-data counterpart of every gate is listed in plan.md section 10.2.

What is not here: the helpers shared by the gates (synthetic world, flow colouring, toy trainer, equivalence tool) are in `support/` (`support/README.md`); the early studies that measured something and printed numbers (flow, box head, radar encoding, temporal block, camera-only / radar-only decoders, S1 pipeline; they were named `test_*` until D48, 2026-11-03) are in `../studies/early/` (`../studies/early/README.md`). Test files import the helpers through `sys.path.insert(0, "tests/support")`.
