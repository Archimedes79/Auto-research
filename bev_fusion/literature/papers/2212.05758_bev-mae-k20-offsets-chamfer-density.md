# 2212.05758 BEV-MAE: decode 20 point offsets per masked BEV cell with Chamfer, plus the point density

| code / licence | https://github.com/VDIGPKU/BEV-MAE (page says "will be released"; release and code licence not checked); paper CC0 |
| verdict | use (the decoder form: K slots of offsets per BEV cell + density; lidar only) |

**What it does**: Masked autoencoder on a BEV grid of lidar voxels. BEV-guided masking (whole BEV cells), a sparse-conv encoder on the visible part, a learnable point token in the masked cells and a decoder that is a SINGLE 3x3 conv layer (a transformer block and a residual block were tried and were worse and costlier). Two linear heads per masked cell: (1) a fixed set of 20 points, as offsets from the cell centre divided by the cell size, trained with Chamfer distance averaged over masked cells; (2) the point density (points per occupied volume), Smooth-L1. The loss weights are not stated on the page.

**Results that matter** (checked): Waymo, 20 percent of the labels, CenterPoint, L2 mAP / APH: scratch 65.60 / 63.21; coordinates only 66.20 / 63.71; coordinates + density 66.70 / 64.25; density alone 65.80 / 63.27 (so density adds +0.50 / +0.54 on top of coordinates). nuScenes test: 71.7 NDS / 67.0 mAP (73.6 / 69.6 with a modified structure) against 70.2 / 65.5 for the TransFusion-L baseline. Cost: 38 h for 30 epochs on 8 P40 (Waymo, all data); BEV-guided masking 4.1 GB vs 12.6 GB for voxel masking, 1x vs 1.4x training cost; BEV-MAE 38 h vs 60 h for GD-MAE.

**Transferable technique**: this is the K-slot-per-cell decoder our question asks for: per cell a (K, 2) offset block, K fixed (20 for lidar; 3 to 4 for radar), Chamfer between the K predicted and the true points of that cell, and a SEPARATE count / density head because Chamfer cannot see multiplicity (see 1906.06565). As an auxiliary loss on the radar BEV the same head would be applied to the cell's OWN feature (autoencoding, not masked prediction), so that a drop of the reconstruction recall shows where the encoder loses detections. Extend the slot with the attributes (Doppler phase, RCS, age, codes) by regressing them per slot, with the slot order fixed by sorting on range.

**Cost and fit**: one 3x3 conv + two linear heads: well under a millisecond at 120 x 104; used only in training. 

**Doubts**: lidar, masked prediction (the decoder reconstructs a cell from its neighbours, not from itself); there is no recall-within-tolerance number, only the downstream detection gain; the gain from the coordinate loss alone is +0.6 mAP, small against seed noise (not stated); no radar.
