# 2511.20003 Radar static-moving segmentation with ego-motion estimation from the Doppler sine pattern

**What it does**: Input is a window of T=8 raw radar point clouds with radial velocity, range and azimuth only, no aggregation, no odometry. A shared per-point MLP with average pooling gives a global vector per cloud, a GRU runs over the 8 vectors, the temporal vector is concatenated back to the point features and decoded by a second MLP into two sigmoid heads per detection: static probability and moving probability. Static returns obey a sinusoidal radial-velocity relation with the azimuth angle, v_r = f(vx, vy, theta); initial static weights feed a weighted least-squares fit for the sensor velocity (vx, vy), the fit recomputes static weights from a Gaussian residual (sigma 0.013), moving weights survive only where the static weight is low. Labels use a 0.1 threshold on both; DBSCAN can cluster moving points into instances.

**Results that matter** (RadarScenes, leave-one-out, radar 3): moving-point segmentation IoU 0.86, F1 0.92 (Table II; Table IV F1 0.93, false-discovery 6.4 %, miss 7.6 %); ego-motion RMSE 0.37 cm/s for vx and 0.12 deg/s yaw rate; 0.15 M parameters. Miss rate about 5.2 % within 15 m and 7.5 % at 100 m. No latency figure, no point count N.

**Transferable technique**: with ego velocity known (we have the pose), the expected static radial velocity of every return is a closed formula, so a moving mask needs no network: residual of v_r against the predicted static value. That mask routes radar returns into a static channel (accumulate with ego warp) and a moving channel (object-level handling). Only the sine model is the transferable part; a learned classifier is the optional extension.

**Cost and fit**: 0.15 M parameters, point-level, trivially cheap. Generalisation of this network to nuScenes radar is not shown (memory: nuScenes radar is sparse and noisy, not checked). A radar-only mask, camera not involved.

**Doubts**: RadarScenes, a different sensor than nuScenes; the static model assumes zero lateral vehicle speed and a rigid sensor mount; the ego-compensation of Doppler is the one step our frozen GaussianCaR radar features do not expose if we only have the rasterised BEV.
