# net - the model: preprocessing, network, losses

The model of the camera + radar BEV system, separate from the training system (`../training/`) and from the tooling that starts, stops and watches trainings
(`../../autoresearch/research/`, `../../autoresearch/trainkit/`). Three layers, each importing only itself and the layers
before it: **prep** (preprocessing) < **model** (network) < **loss** (losses); `training/` stands above all three and nothing here imports it
(`../tests/test_net_layering.py` checks that; its named exceptions: the offline cache builders of prep run the frozen camera heads, and
`prep/feature_cache.CachedBEVFusionModel` forwards to `model/cached_model` inside the function). Modules are imported flat: `netpath.py` puts the three folders
on the path (an old run's snapshot is one flat folder: then the three folders do not exist and nothing is added). Plain PyTorch (env `gcar`); the self-tests run as
`python net/<layer>/<module>.py` from `problems/bev_fusion/`. A gate named below that is not in `../tests/` is a test of v1, kept in the tag `v1`.
