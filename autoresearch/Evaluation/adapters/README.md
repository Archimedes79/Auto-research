# Evaluation/adapters

Small adapters that ship with the suite, for its selftest and as the template of a project's own adapter (`../README.md`, "Try it").

| file | what |
|---|---|
| `minimal.py` | the whole adapter in about 70 lines: a moving disc in noise, a thresholding "network", one metric; copy it to start a project's adapter |
| `toy.py` | the test bed: synthetic videos, a numpy "network" with a memory, two metrics, an overview view |
