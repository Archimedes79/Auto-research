**What it does**: Radar-diffusion: the radar points of 5 consecutive frames are aggregated with the relative poses into a 256 x 256 BEV image (height coded as grey value), a mean-reverting-SDE diffusion model with an objective that treats blank and detected regions separately produces a denser lidar-like BEV image, which is read as points. RadarHD (the baseline): a 64 x 256 polar heat-map (range 0-10 m, azimuth -90..90 deg) of the 40 most recent frames as channels, an asymmetric U-Net to a 512 x 256 lidar-style image, loss pixel BCE + Dice, then threshold to a list of (x, y) points.

**Results that matter** (checked, Table I of Radar-diffusion; metrics in 2D, lower is better): VoD (7,831 train / 635 test frames): RadarHD FID_BEV 247.2, CD 0.34, MHD 0.24 -> Radar-diffusion 118.4, 0.19, 0.10; on the RadarHD data set Radar-diffusion is worse in CD (0.59 vs 0.44) and MHD (0.50 vs 0.34) and better in UCD / UMHD, which the authors attribute to extra points without lidar counterparts. RadarHD alone: median Chamfer 0.36 m and MHD 0.24 m in the training environment, 0.8 m / 0.75 m and 1.03 m / 0.94 m in two unseen environments. Training of Radar-diffusion: one RTX 4090, batch 8, about 9 h, model file 306.7 MB; inference time not reported.

**Transferable technique**: the evaluation vocabulary for "decode the radar grid back to points": Chamfer, modified Hausdorff, their one-directional versions (UCD / UMHD: how many REAL radar points have a reconstructed neighbour; the right one for a lossless-encoder test, because it is blind to extra points), with the scale 0.2 to 0.4 m on VoD as the level that current methods reach when the target is lidar. For our test the target is the radar's own input, so a good encoder should be far below that scale (sub-cell, about 0.1 m) at recall near 1.

**Cost and fit**: diffusion is too heavy for our budget; the aggregation of 5 frames by relative pose into one BEV image is exactly the raster-once-after-point-alignment baseline.

**Doubts**: the output is generated (hallucinated) lidar-like structure, so low CD does not show information preservation; the BEV input carries only height as grey value (no Doppler, RCS); two data sets disagree in sign, so the ranking of methods depends on the data set.
