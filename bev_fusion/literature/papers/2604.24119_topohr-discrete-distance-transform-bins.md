**What it does**: a dense BEV auxiliary head is supervised not with the binary centreline mask but with the Euclidean distance to the nearest centreline point, clipped at half the lane width, normalised to [0, 1] and quantised into 6 uniform bins ("discrete distance transform", DDT); loss = cross-entropy + Dice over the bins. The detection head is focal + L1 as usual. The BEV segmentation features feed the point-level queries.

**Results that matter** (OpenLane-V2 subset_A, Table 3): no segmentation head DETl 26.8 / TOPll 23.1; binary mask 32.6 / 29.8; continuous DT (regression) 32.0 / 29.8; DDT 6 bins 34.6 / 30.6. So the binned target is +2.0 / +0.8 over the binary mask and +2.6 / +0.8 over regression. The paper does not tune the bin count or compare regression with a tuned robust loss. Cost: 12.6 FPS on an RTX 4090; point-level queries plus DDT head add 13.8 % parameters (together).

**Transferable technique**: an arm for our line layers: predict K bins of the distance (e.g. K = 6-8 over [0, 2 m] at 0.5 m cells), loss = CE (soft-label version: Gaussian-smeared bin target for registration tolerance) + the tolerant Dice, decode sub-cell by the expectation over bin centres (differentiable) instead of the Huber field. Spec test: one-hot bin -> expectation equals the bin centre; a target between two bins split by linear weights decodes back to the true distance within 1e-6.

**Cost and fit**: K channels instead of 1; a CE per cell; same GT as now (the distance field we store). Ordinal structure is ignored by CE, which is why a smeared target or a cumulative (ordinal) CE is a sensible variant to test.

**Doubts**: the gain sits on a centreline detector with queries, not on a dense map head; single seed, no variance; the "continuous DT" arm may simply be badly tuned (no robust loss named); a 6-bin target also changes the Dice term, so the effect is not isolated.
