### 3.17 Loop 11: temporal fusion as a building block of the learned chain (how the literature entered; what each element gave in our experiments)

Temporal fusion is the one block of the loop-10 chain that the experiments of loop 10 did not touch. The works below were known from the literature survey of loops 7 and 8 (section 3.12); they were not re-checked against the papers for this loop, so the descriptions are summaries from the earlier survey; the last column is ours (nuScenes TEST, camera + radar BEV features, 21 scenes, synthetic failures; sections 7.27 - 7.29).

| Work | Idea | Where it entered | What came out in our experiments |
|---|---|---|---|
| BEVFormer (ECCV 2022) | temporal self-attention: the BEV features of the previous frame, aligned by the ego motion, are keys and values of the current BEV queries | the ego-motion warp of the memory (E105), as a fixed sampling instead of attention | a fixed warp of the input of the previous frame, mixed into the current one, raises the F1 of the learned extractor under failure and slightly in the clean phase; no comparison with an attention-based memory was run (section 7.27) |
| StreamMapNet (WACV 2024), SQD-MapNet (ECCV 2024) | a streaming memory: BEV features of the past are fused into the current frame, the map queries are propagated | memory = fused input of the previous frame (E105); a memory of the route probability of the vertices (E106) | the memory of the input helped; the memory of the route attribute gave nothing in our protocol. E106 averages a probability, it is not a query propagation, so it says nothing about StreamMapNet-style query memories |
| MapTracker (ECCV 2024) | map elements are tracked as a sequence, a memory buffer of BEV and vector latents with strided selection | not implemented (learned memory); E80 (loop 7) is the evidence that a learned memory did not beat the fixed average on the lane output | the training-free memory of E79 and E105 is the reference |
| HRMapNet (ECCV 2024) | a rasterised map accumulated from past predictions as a prior for the current frame | E105 is a one-step recurrence on the input, related but much simpler: no global accumulated raster | see E105 |
| ConvGRU, RAFT update operator (ECCV 2020) | gated recurrent update of a dense state | not used: no sequences with failure-phase inputs for training (only 842 train rows and 291 VAL rows have perturbed features, without dense maps) | open: a gate trained on perturbed sequences (section 8.7, next steps) |

Takeaway: the literature fuses in the BEV feature space and propagates queries; both are differentiable, and the chain could use fixed forms of them (warp, convex combination, kernel association). Section 3.14 reports a learned temporal model under simulated camera failures for vector-map heads (MapBench); what the sources we know do not report is a training-free memory for a sparse lane-graph extractor and a memory of the navigation attribute, and that is what E105 and E106 measure on synthetic failures.
