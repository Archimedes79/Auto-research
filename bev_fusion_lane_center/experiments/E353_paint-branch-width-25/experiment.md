## 1. Card text
- **Statement:** the 0.5 m paint branch of E324 s can run at a quarter of its hidden width with at most 0.01 topo F1 lost against E324 s AND against the same schedule without narrowing, on both seeds and all three read-outs, after a short end-to-end fine-tune.
- **Mechanism:** E345: the lowest-importance 75 % of the branch's hidden channels are almost unused by the topology metrics (+0.002 with no retraining); E348: the whole branch is worth little (inside the band on every read-out after retraining, one noise-level guard miss). A quarter of the width keeps the paint evidence alive for a quarter of the cost.
- **Surgery (what is true of this architecture, version 2):** the hidden block is Conv(bias=False) -> GroupNorm(8, 32) -> ReLU. Keeping an arbitrary 25 % of the channels would give GroupNorm(8, 8) (one channel per group) and change every kept channel's function; so WHOLE GROUPS are kept (2 of 8: GroupNorm(2, 8), the groups' statistics of the kept channels are unchanged), the groups ranked by the summed channel importance of E345 (so the channel set differs from the probe's per-channel 75 %: the step-0 row n1z is the measurement of what this costs before the fine-tune). The next conv has no bias: a new bias tensor takes the folded calibration means of the removed groups (exact except at the zero-padding border). The equality test of the build compares the narrowed model with the hook-ablated model that removes the same groups, on interior pixels.
- **What exists:** E345's ranking (`calib.pt`, `sweep.json`, `table.csv`), the cost table (`evaluation/jprune_cost.py`), the stored E324 s checkpoints, the E348 stage-0 controls, `jrule_removal.py`, `jends_train.py` (frozen: its loss and its trainable set are reused). **To build (a coder step, running; new files only; a code critic pass before any GPU run):** `training/grid/jnarrow.py` (the group-wise surgery, spec round trip, MAC check), `training/train/jnarrow_train.py` (fine-tune from the FULL stored state, `--init`, `--narrow`, `--seed` honoured, the loss of `jends_train` unchanged, resume; the surgery-aware dump / score / timing wrapper that patches the model loader inside its own process), tests with mutants, README rows; the exact saved GMACs of the chosen groups are written into this card before the first launch.
