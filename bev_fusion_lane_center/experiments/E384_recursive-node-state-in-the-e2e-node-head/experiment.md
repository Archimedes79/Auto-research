## 1. Card text
- **Statement:** a feature-level recurrent state in B''s node head, trained through the node head and the champion head by S4's joint loss with one frame and one scan as input at inference, raises the node coverage and with it the topo F1 by >= +0.005 over the same joint trainer without the state.
- **Mechanism, and the measured failure it attacks:** the node set is the ceiling of the whole system: the token set's GT-node coverage is 0.952 / 0.954 on VAL against 0.981 / 0.982 on TRAIN (B' is better on frames it has seen), c-hi (the GT links over the matched tokens) is 0.819 / 0.820 topo F1 against the champion's 0.668 / 0.676; missed nodes are missed ENDS and junction nodes (E299: the end misses dominate). The earlier tests put the past AFTER the nodes (token states, junction layer, pair re-scoring), where the nodes are already lost; here the state sits at the grid where the existence logit is formed, and S4's loss makes it learn what the delivered graph needs, not what B's own node loss needs. A node that is weak in this frame (occlusion, a faint end) but was strong two keyframes ago is exactly what a carried state can keep.
- **Why this is not a closed question:** E299's re-open clause ('a learned heat-side state'), E354's named limit (the ends, the heat level) and S4 (the node head is trainable end to end for the first time) are the three things that did not exist when the others were tested. Priors against: all four earlier temporal results are null, the end misses are correlated across frames (E299: a state sees the same blind spot), the recall ceiling of the past is +3.2 points in total (E368 step 0) with +0.6 on topology nodes: **the expected gain is small**, the prediction says so.
- **One frame, one scan (D91):** at inference the input is the current frame's 39 channels and the carried state; nothing else. At TRAINING the sequence loader feeds 3 consecutive keyframes in order, the state is the only thing that crosses from one to the next (no second frame reaches a head); the stream read-out is the delivered mode; the truncated read-out is reported.
- **Prediction (+0.003 on topo F1, window -0.003 to +0.010; node coverage +0.004):** E368's right past added about +0.002 at the token level, E354's junction-level state nothing; a state in the node head can act on the node set: a small positive effect is plausible, a TIE the likeliest outcome. **Outcome odds: KEEP about 10 %, TIE about 70 %, CUT about 20 %** (the sequence training costs the head some single-frame steps: z carries the same data path so this is controlled).
- **Dependence on S4 and the re-basing rule (written now):** the arms start from S4's `s4` recipe. If S4's verdict is S4-HOLDS, the card runs as written. - **E2E:** yes: the state, the node head, the token gather (soft, no gradient through the top-K index, the named budget) and the head are trained under one loss; the ego warp is a fixed bilinear resampling of the state with the stored pose (a geometric operator, no learned rule step).
