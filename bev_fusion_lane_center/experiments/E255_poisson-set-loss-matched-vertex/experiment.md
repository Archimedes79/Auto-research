- **Statement**: replacing the clamped hinge recall term by the matching-free Poisson set likelihood does not lift Q, lanes found or R@1_far of the j1 fine-tune once both are compared at the same vertex budget on the same distance map.
- **Mechanism**: the set likelihood normalises over the number of nodes, so the validity scores spread (E244: best Q at tau 0.12 - 0.2, 18.8 vertices per 100 m at the best Q) and the graph becomes vertex-hungry; at 14.3 vertices per 100 m it loses geometry. The hinge recall term pulls scores of missed points directly.
- **Prediction** {value -0.045, tolerance 0.020, class "a loss replaced instead of added, plain control gains about +0.005 from the 50 % checkpoint to the end"}: Q a - c = -0.045 at the matched budget (VAL 873, one seed); lanes found a - c -0.04. Revised after the referee: the E244 50 % reading was -0.057, the Poisson term plateaued at iteration 300, so the full schedule closes little.
- **Decision rule**: matched-vertex procedure, fixed before the run and equal for both arms, each control seed with its own grid: on the 250-frame VAL subset (val250, tuning data, declared) sweep tau in {0.12, 0.2, 0.3, 0.5, 0.7} x vtx_r in {1.5, 2.0, 2.5, 3.0, 3.5, 4.0}; for each tau interpolate vtx_r linearly to vert100 = 14.3, take the tau with the highest interpolated Q (upper envelope; no max over grid points), evaluate that (tau, interpolated vtx_r) on VAL 873 (`val_m143.json`) and report the 623 held-out frames (873 minus val250) separately; the point is valid if vert100 on VAL 873 is within 14.3 +- 0.2, else it is reported as such. Then: CUT if Q a - c <= -0.020 on one seed; KEEP only if Q a - c >= +0.010 on both seeds and on the held-out frames with lanes found >= +0.05, R@1_far >= +0.03 and topo_F1 loss <= 0.005; between: INCONCLUSIVE, seed 1 is added (TIE if still inside the band, then the plain fine-tune).
- **Test design**: arm a seed 0 trained now (about 25 - 45 min on a quiet GPU); controls are the existing exact-map fine-tunes e24_j1ex_s0 / s1 (E237), reference j1rc from E240; the tuning subset is part of VAL (declared: tuning on VAL for both arms equally); layer 0 (toy tests 7/7 of loop 19), layer 1 (the matched procedure reproduces the stored vertex count of j1eq within 0.3), layer 3 - 4 for the verdict.
- **Cost / kill**: 0.5 GPU h, plus 15 min CPU for the grids (2 threads). Kill: NaN loss, the BN-derail guard, or val250 lanes found 0.03 below the j1 start at 1 u; a run that shared the GPU or ran at a 1-minute load average above 6 is not decided and is repeated (E244 was lost that way).
- **Inputs**: ready (loss code, launcher `temp/loop19/train_j1.sh`, controls); to build: registry entry `e25_j1phd2_s0`, `temp/loop20/e255_matched.py`.
- **Referee** (2026-10-26, ar-referee): REVISE (it is a closing run for K193 under the rules E244 lacked, 0.5 GPU h, not a new idea: nothing changes in the loss or the weights, only schedule length, exact map, matched vertices; say so and do not expect KEEP).
