# 1711.02257 GradNorm: gradient normalisation for adaptive loss balancing

| verdict | use (cheap loss balancing between a lane head and a detection head) |

**What it does**: Learns one loss weight w_i per task by pushing each task's gradient norm at the last shared layer towards a common target scaled by the task's relative training rate (memory: target G_avg * r_i^alpha, loss L1 on the gradient norms). One hyper-parameter alpha. The page confirms that claim "dynamically tuning gradient magnitudes" and that it matches or beats grid search.

**Results that matter**: no numbers on the abstract page; the claim is parity with exhaustive weight search across regression and classification tasks.

**Transferable technique**: the shared layer is our BEV feature map, so the gradient norms are measured at the last shared conv. One extra backward pass per task through the last shared layer per step; weights renormalised to sum to the task count.

**Cost and fit**: costs an extra gradient computation per step; a BEV net with 2 to 4 heads can afford it. Compared to a hand-tuned focal-weight sweep it saves runs.

**Doubts**: in later benchmarks it is often not better than a tuned fixed weight (memory, not checked); needs a clean choice of the shared layer; dense thin-structure losses vs. sparse heatmap losses differ by orders of magnitude, so a fixed warm-up scale is still needed.
