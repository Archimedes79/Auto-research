# training - code of the camera + radar BEV system

Plain PyTorch (env `gcar`: PyTorch 2.8, Python 3.12, no mmcv). Every module has a self-test with known answers (`python training/<module>.py`).

| file | what it does | self-test |
|---|---|---|
| `camera_encoder.py` | front-camera encoder with pre-trained camera heads: ResNet-50 + CustomFPN + DepthNet (camera-aware gate, 27-vector) with DualBEV's layer names (`load_pretrained` reports missing / unexpected / shape-mismatched keys), depth softmax over 118 bins (1-60 m) -> lift PD -> BEV (B, 128, 120, 104); `freeze_camera_heads` keeps backbone, neck, DepthNet frozen with BatchNorm in eval mode; `nuscenes_front_ida`, `camera_vector` | shapes, key names, image transform, one camera alone = in a batch, frozen heads get no gradient |
| `radar_bev.py` | radar block (simple): detections from any rig (position, distance, ray direction in the vehicle frame, Doppler, RCS, age) -> hard raster into the cell they reside in (count, mean properties with direction and Doppler as circular values, sub-cell offset) -> two 3x3 convs -> (B, 32, 120, 104) on the camera BEV grid; `to_vehicle` (sensor polar + pose -> vehicle frame), `doppler_code`; information-preserving variant `rasterize_slots` / `decode_slots` / `RadarBEVSlots`: K = 3 detections per cell stored exactly + remainder mean + count, exact inverse | periodic Doppler code, sensor pose, cell and properties, mean of a cell, frames, rig independence, module; slots: exact round trip of eight fields, several detections per cell, overflow + remainder, module |
| `splat.py` | temporal block: move BEV cells or radar detections to another time - velocity head f_theta (1 x 1-conv MLP, 2 outputs, zero start), positions p' = R(-omega dt)(p + v_hat dt - d) with ego speed / yaw rate (translation first order in omega, rotation exact), normalised bilinear softmax splat with a mass channel; `CorrectionHead` (learned bounded position correction from feature + ego motion, zero start); `ego_speed_yawrate` (v, omega from poses); `splat_bev` for maps, `splat` for points; synthetic scene checks in `../temp/checks/` | exact 2-cell shift, landing point vs formula and exact turn, object velocity, forward-back, mass conservation, collision, gradcheck, head learns, moving blob, v / omega from poses, correction zero start / bound / gradient |
| `fusion.py` | camera-radar fusion at camera time, plug-in modules in front of the trunk: `ConcatFusion` (concat + 3x3 conv, the plan's main), `GateFusion` (per-channel and per-cell cross-gates in the spirit of GaussianCaR's FeatureRectify, re-implemented; `gates()` for plotting), `drop_modality` (modality dropout: one of the two modalities zeroed per sample, never both). Binary-data experiment: `temp/checks/check_fusion_binary.py` | shapes, gradients, modality dropout statistics, no dropout in eval, camera stream unchanged with the radar off, gates in [0, 1] |
| `timed_head.py` | time decoding inside every head: `MotionHead` (explicit velocity field + `loss`), shared `TimeMover` (velocity + ego motion + splat with a mass channel), `TimedHead` wrapper per head (refine block with FiLM by dt, zero start; dt = 0 is the plain head) | dt = 0 = plain head, ego motion at x -+ v dt, unknown share v dt / 60 m, object velocity, motion loss, one mover shared by the semantic and object head, gradients |
| `bev_trunk.py` | BEV trunk after the fusion, the standard flow of BEVDet / BEVDepth / CRN / DualBEV in plain PyTorch with a width factor: 3-stage ResNet pyramid (strides 2 / 4 / 8) + FPN_LSS decoder + semantic head; option `detail=32`: stride-1 detail path (two 3x3 convs at 0.5 m on the input, concatenated before the head); DualBEV layer names (`load_pretrained` loads its BEV encoder: 98 tensors, 0 missing); `light_up` = sub-pixel up-sampling instead of the full-resolution 3x3 conv. FLOPs per candidate: `temp/checks/trunk_flops.py` | shapes of the three stages and the output, parameters + BatchNorm statistics = DualBEV's 26,668,896 tensors, light variants, gradients |
| `gt_bev.py` | GT per nuScenes keyframe on any grid (0.5 / 0.25 m): areas (coverage), dividers (mask + distance field), centre-lines (mask + direction), objects (coverage, velocity, instance), masks (camera, occluded, radar, undefined), exact map polylines in `meta["vectors"]`; `training_sample()` = GT of k-1, k, k+1 + the ego steps (v, omega per camera frame) between them; pictures `temp/checks/view_training_samples.py`, map-image alignment `temp/checks/check_gt_vector_vs_cells.py` | square = 4 m^2, line distance, occlusion, 0.25 m pooled = 0.5 m, next keyframe = current moved by ego motion (IoU 0.988), velocity norms, ego steps |
| `lift_pd.py` | camera block: lookup table per calibration (voxel -> image position + fractional depth bin) and lift PD (pull with depth weight: feature x p(depth) by two grid_sample gathers), height into channels; option learned elevations; `use_depth=False` = lift P | geometry, uniform depth = P / D, one-hot depth, rig shift (camera 1 m forward = BEV shifted 2 cells), gradcheck incl. learned heights, module |
