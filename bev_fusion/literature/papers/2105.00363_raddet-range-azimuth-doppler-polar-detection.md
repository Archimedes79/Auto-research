**What it does**: Input is a 256 x 256 x 64 range-azimuth-Doppler tensor (log magnitude, dataset-wide mean / variance normalisation); RadarResNet (max-pool downsampling) gives 16 x 16 x 256. The RAD YOLO head predicts boxes on the polar RAD grid (output (16, 16, 4, anchors, 7 + classes): objectness, 3D centre and size; anchors by K-means on the ground truth). A second 2D head first maps polar features to a 32 x 16 x 256 Cartesian map with a learned coordinate transformation layer (channel-wise fully connected layers + a residual block) and then applies a standard YOLO head.

**Supervision**: loss = 0.1 * box + objectness (focal, alpha 0.01 for negatives) + class (CE). About 10,158 frames, TI AWR1843, sunny weather, semi-automatic labels (about 75 % automatic) corrected by hand, 80 / 20 split.

**Results that matter**: 3D head AP 0.563 at IoU 0.3, 2D head AP 0.516 at IoU 0.5 (RadarResNet max-pool). The page does not run a polar-versus-Cartesian ablation, so no claim about which coordinate system is better follows from it.

**Transferable technique**: a learned polar-to-Cartesian layer built from channel-wise FC layers is a learned alternative to our fixed lookup resampling; for a fixed sensor geometry the fixed table is cheaper and exact, so we would only borrow the idea if the table were wrong (for example for mounting-error correction).

**Cost and fit**: small dataset, no nuScenes. Not a radar-spread method.

**Doubts**: small dataset (about 10 k frames, one radar, sunny conditions only), semi-automatic labels, class imbalance noted by the authors, no polar vs Cartesian control.
