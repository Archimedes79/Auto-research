**What it does** [checked]: for the current time t the detector holds BEV features B_{t-N} ... B_t, each built from the images of its own time. To predict the objects at t-k, HoP removes B_{t-k} from the set and builds a pseudo BEV feature for t-k from the REST (temporal position embeddings added first): a short-term decoder (grid-shaped learnable queries, deformable attention over the two neighbours B_{t-k-1} and B_{t-k+1}) and a long-term decoder (all remaining frames, channel reduction r = 4 first), outputs concatenated and fused by a 3 x 3 conv. A light CenterPoint head predicts the objects at t-k; the GT boxes of t-k are transformed into the current ego frame. Used only in training: no inference cost. Default k = 1, 4 previous frames. The loss type and weight are not given in the text read.

**Results that matter** [checked, nuScenes val, ResNet-50]: BEVFormer-opt 51.3 NDS / 41.4 mAP to 53.1 / 42.8 with HoP; BEVDet4D-Depth 49.3 / 38.5 to 50.9 / 39.9. Decoders: none 51.3, short-term only 52.8, long-term only 52.6, both 53.1. Which time is predicted (NDS): the FUTURE frame t+1 52.3, k = 1 53.1, k = 2 53.4, k = 3 53.6 (but 2.3 x the memory for k > 1 in their table). Supervision: features only 51.8, 3D objects 53.1. Not detaching the historical BEV features of the last two encoder layers: 53.9 (+0.8) at 2.1 s/iter against 1.9 with detach and 1.6 without HoP (8 x A100; BEVDet4D-Depth 4.5 to 4.7 s/iter). Query fusion alone 52.5; both without detach 54.4.

**Transferable technique**: our plan decodes t_c +- 0.5 s from one state (8.2); HoP is the published evidence that a PAST-target loss helps by itself (+1.6 to +1.8 NDS) and that it helps more than a FUTURE target (53.1 vs 52.3, one run each, no seeds). Cheapest use for us: the dt = -0.5 term of the multi-time loss exists from week one; what to copy is (a) the target is hidden from the input (the image of t-k is not used), the same as for our decoded dt; (b) the cost model: +5 % (detached, BEVDet4D) to +20-30 % (BEVFormer) training time, nothing at inference; (c) the memory cost grows with every extra decoded time (k > 1: 2.3 x), so budget dt in {0, -0.5, +0.5} before {+-1.0}.

**Cost and fit**: the two attention decoders are heavy for a 3060; our splat + refine block is the cheap replacement. Gradient through history costs +0.8 NDS for +10 % time here: relevant to the detach decision of the temporal window.

**Doubts**: single runs, no seeds, no noise band (the gains of 0.8-1.8 NDS are within what seeds can move on nuScenes); loss weight unreported; detection (sparse targets) not dense map layers; summariser could not read the table column assignment reliably (the text gives 52.7 for long-term only where the table says 52.6).
