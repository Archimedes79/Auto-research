**What it does**: the usual soft Dice / soft IoU is not minimised at prediction = target when the target is soft: the paper's example, soft label y = 0.5, soft Dice is minimised at x = 1 ("clearly erroneous"). The semimetric forms replace the denominators by L1 norms so that the minimum is at x = y while remaining identical to soft Dice for hard labels (Theorem 2.2). Formulas (x prediction, y target, L1 norms): DML1 = 1 - (|x| + |y| - |x-y|) / (|x| + |y|); DML2 = 1 - 2<x,y> / (2<x,y> + |x-y|); Jaccard: JML1 = 1 - (|x| + |y| - |x-y|) / (|x| + |y| + |x-y|); JML2 = 1 - <x,y> / (<x,y> + |x-y|). Training mix 0.25 CE + 0.75 DML.

**Results that matter** (5-fold; Dice %): Table 6, soft labels (QUBIQ weighted-average labels; LiTS / KiTS knowledge-distillation labels): QUBIQ hard 72.99, soft Dice 73.79, DML1 76.59, DML2 76.42; LiTS 57.92 / 58.12 / 59.31 / 59.12; KiTS 67.96 / 68.26 / 69.29 / 69.07. Label smoothing helps calibration slightly (LiTS UNet-R50 Dice 59.79 -> 60.59, ECE 0.51 -> 0.49). Gains over soft Dice are +0.2 to +1.2 on the large organ tasks, +2.8 on QUBIQ (7 tasks with real rater disagreement).

**Transferable technique**: in `soft_iou_loss(prob, target, w)` replace i / u by JML2 with the same weights: loss = 1 - sum(w p t) / (sum(w p t) + sum(w |p - t|)). Our own derivation (checked by hand, not run): with t = 0.5 on one cell the present soft IoU gives 0.667 at p = 0.5 and 0.5 at p = 1.0, i.e. it prefers p = 1; JML2 gives 0 at p = 0.5 and 0.5 at p = 1. Spec test: p = t (soft) must give exactly 0 with zero gradient; hard 0/1 targets must reproduce the old value (JML2 = soft IoU for hard labels). Fractional cells matter most for pedestrians and two-wheelers: at 0.5 m a 0.3 m circle is almost all fractional cells (our inference from the footprint size). Ignore masks and per-cell weights go in as in the existing `_wsum`.

**Cost and fit**: one extra |p - t| reduction, same order as the existing term; no hyper-parameter; drops into the area (0.5 x IoU) and dense-object terms. Not needed for the line terms (their masks are binary).

**Doubts**: gains are shown on medical organs with rater-averaged labels, not on geometry-derived coverage fractions; triangle inequality only with a relaxation factor (not needed for training); the paper's own Table 6 caption (Dice) and text (BDice) disagree for QUBIQ; the licence of the repo is unclear.
