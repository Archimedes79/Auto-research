# 2304.06547 RadarGNN: invariant graph network on radar points (CVPRW 2023)

**What it does**: Radar points (RadarScenes) are the nodes of a kNN graph (k = 20, accumulated over 500 ms, timestamp t as node feature). Three input variants: non-invariant (x, y, vx, vy, RCS, t, degree c); translation invariant (no absolute position, relative offset dx, dy on the edges); translation + rotation invariant (velocity reduced to its norm, edges carry point-pair features: distance, relative angle of the two velocity vectors, angles between each velocity and the connecting line). A generalised message-passing layer with shared MLPs for node embedding and update and MAX aggregation (not attention; 4-layer node MLP, 3-layer edge MLP; layer count and widths not reported). Heads: segmentation and bounding box.

**Results that matter** (RadarScenes test; checked): detection mAP at IoU 0.3 = 56.5 (val 60.2 vs YOLOv3 55.9, PointPillars 36.1); segmentation macro F1 77.1 vs recurrent PointNet++ 75.0, PointNet++ 74.3, PointPillars 47.6. Invariance ablation (mAP / F1): none 19.4 / 68.1; translation 56.5 / 77.1; translation + rotation 19.6 / 76.5. Latency and parameters are not reported.

**Transferable technique**: dropping absolute position and feeding relative offsets is worth +37 mAP for a graph network; adding rotation invariance on top destroys detection (19.6 mAP) because orientation and the direction of travel need the absolute heading, while segmentation is hardly hurt. For us: relative (polar) offsets between the cell and the detection, YES; rotation invariance of the radar frame, NO - the sensor frame is fixed, and the Doppler direction matters.

**Cost and fit**: graph build (kNN) per frame and PyG scatter ops, irregular and not export-friendly; no timing. RadarScenes is a different radar (77 GHz, 4 sensors) with a different point density from nuScenes.

**Doubts**: only RadarScenes; no latency; ablation of rotation invariance is for one design, the collapse to 19.6 mAP may be partly a failure of the pair-feature design; GPL-3.0.
