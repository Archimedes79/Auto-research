**What it does**: A shallow PointNet with local pooling computes a feature per input point (the point's coordinates are inside the feature); features are projected onto canonical planes (or into a 3D volume) and AVERAGE-pooled per cell; 2D / 3D U-Nets process the planes / volume; for a query point the feature is bilinearly (planes, summed over planes) or trilinearly (volume) interpolated and a small fully connected ResNet (32 hidden features) outputs the occupancy. Binary cross-entropy, Adam 1e-4. The decoder can be queried at ANY position, not only at cell centres.

**Results that matter** (checked): ShapeNet from point clouds, 3-plane 64^2: IoU 0.884, Chamfer-L1 0.044, normal consistency 0.938, F-score 0.942 vs the global-latent ONet 0.761 / 0.087 / 0.891 / 0.785; synthetic rooms, volume 64^3: IoU 0.849, Chamfer-L1 0.042, F-score 0.964 vs ONet 0.475 / 0.203. Ablations: bilinear 0.805 vs nearest-neighbour 0.766 interpolation; volume resolution 32^3 -> 64^3 scene IoU 0.782 -> 0.849; multi-plane 0.805 beats single plane 0.773 and volume 0.782 at similar memory. Runtime not reported on the page.

**Transferable technique**: the encoder is lossy in the same way as our raster (average pooling) yet the decoder reaches high accuracy because (1) each point passes through its own MLP with its coordinates BEFORE pooling, (2) the decoder interpolates neighbouring cells and gets the exact query offset as input. So the information-preserving radar cell feature is: per-detection MLP on [exact offset to the cell centre, Doppler code, RCS, age, codes] -> pooled into the cell (mean + max + count) -> small CNN -> decode by interpolation at the true detection position. A cheap probe for losslessness that needs no point-set loss: ask a small MLP to regress the attributes of the detection nearest to a query position from the interpolated BEV feature.

**Cost and fit**: bilinear `grid_sample` at a few thousand queries plus an MLP of 32 units: negligible; the U-Net part is what the radar block already has (two 3x3 convs).

**Doubts**: shape and room occupancy, dense inputs (thousands of points) and a binary target; the reconstruction is of a surface, not of each input point; one pooled cell feature with average pooling cannot separate two nearby detections whose per-point features were similar (nothing in the paper tests two points per cell).
