# 1906.06565 DSPN: predict a set by gradient descent on a latent; Chamfer cannot see multiplicity, Hungarian can

**What it does**: A set decoder with no output-slot order. A learnable initial set is refined by T gradient steps so that its encoding (a permutation-invariant set encoder) matches the target latent vector; the outer loop trains the encoder through the inner steps. Because the updates of a set are permutation-equivariant, the "responsibility problem" of MLP decoders (fixed output slots forced into an arbitrary order) does not arise.

**Results that matter** (checked): point-set MNIST auto-encoding, Chamfer x 1e-3: DSPN 0.09 +- 0.01, MLP decoder 0.21, RNN decoder 0.49. CLEVR bounding boxes AP95: 85.7 (10 iterations) vs 57.9 for the MLP (the authors report an evaluation bug and corrected figures in the appendix, lower but the same order). Cost: with T = 10 inner steps CLEVR training takes about 75 percent longer. Loss analysis: Chamfer is O(n^2) and fails on multisets (a set {a, a, b} and {a, b, b} have loss 0); Hungarian gives a one-to-one matching at O(n^3).

**Transferable technique**: for a cell-aligned decoder the matching problem almost vanishes: each cell has at most K = 3 to 4 detections, so (a) fix the slot order by sorting on range, which removes the responsibility problem, or (b) take the minimum of the loss over the K! permutations inside the cell (6 for K = 3, 24 for K = 4; trivially cheap, an exact Hungarian). A Chamfer-only loss lets two slots collapse onto one true point (multiplicity is invisible), so always add a count / occupancy-per-slot term (BCE) next to the position loss, as BEV-MAE adds the density. For a global (non-cell) decoder the same paper shows why the Chamfer / EMD choice matters: Achlioptas et al. (1707.02392, row in the table) report the EMD-trained auto-encoder gives better generative results than the Chamfer-trained one at higher cost, and CD "misses partially good matches".

**Cost and fit**: not needed; for K <= 4 per cell the exhaustive permutation min is the cheap exact form.

**Doubts**: MNIST point sets and CLEVR, 2D / low-dimensional; the iterative decoder costs T forward passes; no radar, no attributes, no latency on the GPU of interest.
