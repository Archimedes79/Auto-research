## 1. Card text
- **Statement:** (i) the speed path (the same head function, a loss without host syncs, a GPU-resident loader with the plain loader's data order) trains the champion recipe to the champion's quality; (ii) a budget of the 384 highest-existence predicted nodes per frame keeps that quality within the written margins at about 1.8 x less pair work.
- **Mechanism:** (i) none claimed beyond the test result: the loss, the gradients and 20 steps of weights agree with the plain path (CPU fp32: loss to 1e-5, gradients to 2e-5, weights after 20 steps to 3e-6; 2 real VAL frames below and above the key-weight switch with the E376 / E377 options and the E379 KD term to 1e-4: `test_jtoken_fast.py`), the loader equals the plain one bit for bit on 24 real VAL frames and in its epoch order for workers 0 and 2 (`test_lane_ptok_gpu.py`). (ii) all pair tensors (attention bias MLPs, the wiring logits, the softmaxes) scale with K^2, the head is GPU-bound, and the low-ranked tokens are mostly duplicates and false nodes.
- **Not claimed:** a gain in quality; anything about TEST; that K 384 is right for the plain lane head B (only `e292_a` = B'); the inference latency (reported only); CUDA graph and stacked runs (measured as not worth it at 83 ms per step: a whole-step graph gains 13 %; reconsidered when the step is below about 20 ms).
- **What the speed path does not cover (the plain trainer stays for them; E379's arms and references use the plain trainer):** `--token-drop`, `--teacher rule`, `--distill-from` (they read keys the GPU batches do not carry; `--cpu-loader` keeps the dense loader and the fast loss), `prior`, S2 / S3 blocks and `live_inputs` (the head delegates to the plain forward), and eval mode (the read-outs run the plain forward through `load_model`, the same weights).
- **Inputs:** the K 512 caches of seeds 0 / 1, the E373 heads and dumps, the read-out tools (`jtoken_eval.py`, `choose378.py`); to build: the K 384 caches in `runs/e383_cache` (the builder took 1 - 4 minutes per split and seed for K 512: E365.tc_*). The speed path imports only names that are on main (`jtoken_fast.py` inlines `source_rows`).
