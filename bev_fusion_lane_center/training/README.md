# training - the system (models, data, losses, training, inference)

Long-lived code of the lane-graph chain. All modules are imported flat (`import p16_builder as PB`); the launcher `tools/env/_py14.sh` puts every folder on `PYTHONPATH`, so a module can move between the folders below without breaking imports. **New model code goes here; one-off analysis does not (that is `temp/`).**

| folder | role | files (main ones) |
|---|---|---|
| `architecture.json` / `.svg` / `.md` | the architecture drawing of the delivered chain: the spec (boxes, arrows, the code each box stands for), the picture and the file map with the end-to-end table (generated by `../../autoresearch/tools/archdraw.py`; `archdraw.py check training/architecture.json` run from the problem folder fails when a named file or symbol is gone, a file here is in no box, or the picture is stale) | 
| `trainer.py` | **general trainer** for new work: AdamW + warm-up / one-cycle, AMP, clipping, checkpoint every N steps with RNG state, `resume=True`, skip of non-finite steps (loss or gradient; `max_bad` in a row, or a run that never updated a weight, FAILS), loss-spike roll-back, a data loader is iterated anew every epoch, a run that skipped more than 5 % of its steps ends `done` with a WARNING and `skipped_share` in status.json, `done` flag only after success. Self-test: `trainer_selftest.py` (crash at step 120 + resume gives the same weights as an uninterrupted run; a finite loss with a NaN gradient never reaches the weights; diverged and all-skipped runs fail; the loader is reshuffled each epoch). | the old scripts below carry their own copies of this boilerplate The run directory follows the trainsuite contract (2026-11-03, copied from the BEV system's trainer): `config.json`, `log.jsonl` (rows with total, lr, grad_norm, s_per_step, gpu_gb, the loss's scalars; `probe=True` adds `grad.<module>`, `upd.<module>`, `t_data`, `t_step`), `train.log`, a stop request (`python -m trainsuite stop RUN`: checkpoint, `STOPPED`, exit code 75), so `python -m trainsuite status / health / curves / watch` and `run.py` work on it. |

## Ground rules
- Everything that trains must be resumable and must write `log.txt` / `train.log`, `log.jsonl`, `config.json`, `status.json`, `model.pt` into `runs/<name>/` (use `trainer.fit`: that is the trainsuite contract; retrofit `p17_mapft.py` first - its crash at 3500 / 4800 steps lost 2 h).
- Metrics are not defined here - call `evaluation/` (`sparse_lanes`, `lane_grid`).
- Cached foundation features are read from the WSL home (`~/exp_gcar_b123`, `data/README.md`); nothing here writes there except `prep/`.
- Speed is a criterion: a change of the pipeline keeps the graphs identical (`evaluation/drivers/p16_fast_check.py`).
