**What it does**: set prediction of polylines / polygons with Hungarian matching and permutation-equivalent point order. One-to-one loss = 2 L_focal(class) + 5 L_p2p (Manhattan distance between matched point pairs) + 0.005 L_dir (negative cosine between predicted and GT edge vectors). MapTRv2 adds a one-to-many auxiliary set (K = 6 GT copies) and dense auxiliary losses: 3 x depth CE + 1 x BEV segmentation CE (binary mask of the rasterised GT map, resolution not stated) + 2 x perspective-view segmentation CE. Total weights beta_o = beta_m = beta_d = 1.

**Results that matter** (nuScenes val mAP over Chamfer thresholds 0.5 / 1.0 / 1.5 m): MapTR-tiny permutation-equivalent modelling 50.3 vs fixed order 44.4; edge-direction loss weight 0 / 0.003 / 0.005 / 0.01 = 48.2 / 49.1 / 50.3 / 48.3. MapTRv2 dense supervision none 56.6 -> all three 61.5 (+4.9); one-to-many K = 0 57.6 -> K = 6 61.5. Speed (RTX 3090): MapTRv2-R18 33.7 FPS, R50 14.1, V2-99 9.9. The "roadmap" table lists cumulative gains +4.9 (depth), +6.2 (BEV), +6.8 (PV) over a 50.3 base; that does not agree with the 56.6 no-dense row, so quote only the dense ablation.

**Transferable technique**: (1) the direction term as a cosine loss on the edge tangent with a very small weight (5e-3 against the point loss at 5) and a clear optimum - for our centre-line direction we use L1 on (cos, sin); a cosine variant is a one-line arm; (2) the claim that a plain CE on the rasterised map as an auxiliary is worth +4.9 mAP for a query head - we already train dense, so nothing new; (3) the one-to-many idea (several positives per GT) is the matching-free analogue of our dilated / tolerant positives.

**Cost and fit**: the matching losses are a hard assignment, which our fully differentiable dense path excludes; evaluation (Chamfer AP) differs from our IoU-at-tolerance metrics.

**Doubts**: no ablation of the focal / L1 terms, no divider-only breakdown; the BEV CE head uses no class balancing in the text; code licence MIT but the paper licence is non-commercial (irrelevant for ports).
