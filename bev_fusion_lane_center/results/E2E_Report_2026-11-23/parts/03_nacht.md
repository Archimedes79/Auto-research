## 3.1 E388: gelernte Dekodier-Schwellen: NO

Der Champion dekodiert mit drei von Hand auf TRAIN gewählten Zahlen (Kurzlinks 0.3, lange Verbinder 0.2, Knoten behalten bei p_none < 0.6). E388 lernt sie per Gradient auf einem weichen F1-Ersatz der gelieferten Entscheidung, auf einer TRAIN-Stichprobe, und liest einmal auf VAL mit dem echten Scorer. **Ergebnis nach der vor dem Lauf geschriebenen Regel: NO, beide Seeds.** Gelernt minus Hand, VAL, gepaart: topo F1 -0.025 / -0.028, junction F1 -0.119 / -0.109, lanes found -0.011 / -0.012; die gelernten Schwellen (kurz / lang / behalten) waren 0.05 / 0.19 / 0.388 und 0.05 / 0.187 / 0.376 gegen die von Hand gewählten 0.3 / 0.2 / 0.6.

**Warum (ehrlicher Befund, E388b).** Die Anpassung tat, wofür sie gebaut war: auf TRAIN selbst verliert die gelernte Zelle gegen die Handzelle genauso (topo F1 -0.0256 / -0.0272), und eine Kreuz-Anpassung auf VAL-Hälften verliert auf der gehaltenen Hälfte ebenfalls. Das heißt: die TRAIN-zu-VAL-Lücke von B' erklärt es nicht, das weiche F1 ist das falsche Ziel für die gelieferte Entscheidung (eine Hypothese aus den beiden Lesungen, kein Beweis). Die Schwellen bleiben von Hand (Regel R7 in `DESIGN.md`).
