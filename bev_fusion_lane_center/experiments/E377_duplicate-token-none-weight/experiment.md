## 1. Card text
- **Statement:** the champion's low none weight (0.25) is right for the none tokens in general (recall) but wrong for the duplicate tokens next to a real node: their own weight 1.0 removes about half of the kept duplicates and raises the junction F1 by 0.03 or more on both seeds at the arm's own decode cell, at an unchanged topo score.
- **Mechanism:** the multi-positive label makes a duplicate token a correct successor of its predecessor (it is in G(i)), so the head learns to keep it and link to it; only its own none terms (type none, outgoing links none) push it out, and the champion weights those by 0.25. A duplicate that is kept emits its own links (0.7 short links per kept unassigned token on VAL) and becomes a second branch at the fork point of its neighbour: a false degree >= 3 point. The weight 1.0 on those terms only (E371's weight for every none token kept 7 % of the duplicates instead of 18 %) restores the push where it is wanted and leaves the low weight on the other none tokens, whose recall effect the champion keeps.
- **E2E / D55:** a loss-only change: the duplicate label is computed in the loss from the batch's training labels (`ytype == none` and the token's column of `y` non-empty), nothing at inference changes (the same head, the same decode, the same four named output thresholds); differentiable as before.
- **Why weight 1.0 (fixed before any run, from the TRAIN measurement above):** among the none weights already trained on the same seeds (0.25, 0.5, 1.0), 1.0 kept the fewest duplicates on the TRAIN sample (7.1 % / 7.6 % against 11.5 % at 0.5 and 18.2 % / 19.9 % at 0.25); it is the E365 recipe's value, so the arm adds no new tuned number; a higher value is not tried (no trained evidence for it; a sweep would be a forking path).
- **Not claimed:** the other none tokens (mid-connector tokens, false tokens), the long wiring (S2 / S3), anything on TEST, that token-level points equal the scorer's junction points.
- **Inputs:** ready: the E365 caches, `jtoken.py` / `jtoken_train.py` (with E376's `--pos-loss`), the read-out tools of b280a87a (`score --ref-run`, `--argmax --keep-thr`, `anatomy`), the E373 heads and dumps.
