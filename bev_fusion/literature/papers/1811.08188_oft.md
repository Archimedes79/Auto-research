# 1811.08188 OFT - Orthographic Feature Transform (monocular, fixed grid, integral image)

**What it does**: a 3D voxel lattice anchored on the ground plane a fixed distance below the camera (80 m x 4 m x 80 m, 0.5 m voxels). Each voxel is projected into the image feature map, its footprint approximated by a rectangle from focal length and principal point, and the features inside are averaged using an integral feature map (cost independent of region size, differentiable). Voxel features are summed along height with learned per-height weight matrices to give the BEV map.

**Along-ray distribution**: none. Depth is not modelled; each voxel pulls a feature from the pixels it projects to and the network learns which ground locations those features matter for (a reverse, voxel-to-pixel direction, no weights along the ray). Hence no uncertainty channel.

**Precompute versus runtime**: projection indices depend only on camera parameters so they can be precomputed; the integral image is a runtime cumulative sum. No ms or GPU in the paper text.

**Flat-ground handling**: ground plane fixed below the camera; vertical structure kept by 4 m of voxels and learned height weights, so objects above ground are not forced onto the ground, but slopes are not modelled.

**Results**: KITTI car, monocular: validation AP3D 4.07 / 3.27 / 3.29, AP_BEV 11.06 / 8.79 / 8.91 (easy / moderate / hard). Very low by today's standards.

**Transferable technique**: voxel-to-pixel sampling gives every BEV cell exactly one lookup per height, with no scatter (no atomic adds), so it parallelises trivially; box-average via integral image gives anti-aliasing at far range where one cell spans < 1 pixel.

**Doubts**: 2018 numbers; no speed; ignores uncertainty entirely; pulling the same pixel for all cells along a ray means the occluded cells behind an object receive the same feature (no visibility).
