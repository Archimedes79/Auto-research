## 1. Card text
- **Statement:** at an equal total none push, placing the none weight on the none tokens next to real nodes (0.73 there, 0.25 elsewhere) keeps at least 0.010 more lanes found than the scalar 0.5 at an equal junction F1, and it raises the champion's junction F1 by 0.03 or more within the champion's guards.
- **Mechanism:** a none token next to a real node is the source of a second branch: kept, it emits its own links (0.7 short links per kept unassigned token on VAL) and turns its neighbour into a false degree >= 3 point; the champion keeps 19 - 22 % of them because its none weight is low everywhere. Pushing only these tokens towards none teaches the head a learned suppression (it sees the twin through the relative-geometry attention and B''s existence), while the far none tokens keep the low weight that the champion's recall came from. A label-defined subset of the none tokens next to real nodes; it caps the effect at the points that touch a near token (62 - 64 %).
- **E2E / D55:** loss-only: the label is computed in the loss from the batch (the training type labels ytype, the token positions and headings), nothing at inference changes (the same head, the same decode, the same four named output thresholds); differentiable as before.
- **Why 0.73 (fixed before any run, from TRAIN counts):** the weight that makes the mean none weight over the TRAIN none tokens equal to the scalar control's 0.5: (0.5 x 263.4 - 0.25 x 125.1) / 138.3 = 0.726 (cache 0), 0.739 (cache 1), mean 0.73; no VAL number entered, no sweep.
