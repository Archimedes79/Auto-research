**What it does**: A point-based network (GNN or KPConv) extracts neighbourhood features from the exact point positions, then a grid renderer and a convolutional backbone detect objects. Aim: no information is lost to grid quantisation, better orientation estimation. nuScenes. Section headings seen: point feature extractor and grid rendering, backbone and detection heads, hybrid training.

**Results that matter** (digest): +19.7 % mAP for the car class over the next best radar-only submission and 11.5 % relative orientation improvement (abstract). The submitted model (KPConvPillars) is listed at 4.9 mAP / 13.9 NDS on the nuScenes test set in the RadarDistill table (checked there), so the car-class gain does not carry to the 10-class benchmark.

**Transferable technique**: the hybrid layout (point stage before the grid) - see 2305.15836 for the version that was read.
