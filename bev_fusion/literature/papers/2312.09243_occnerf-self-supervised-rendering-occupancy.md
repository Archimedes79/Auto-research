# 2312.09243 OccNeRF: self-supervised occupancy by photometric multi-frame rendering, contracted parametrisation

**What it does**: A 3D occupancy volume (300x300x24, central 200x200x16 inside z in [-1, 5.4] m; the outer region is contracted so unbounded depth still gets rays) is rendered to depth with predicted rendering weights directly (no density or SDF). Depth for 3 frames per camera is supervised only by photometric reprojection (SSIM 0.85 + L1, per-pixel minimum reprojection, auto-mask) against a 5-frame sequence. Semantics from an open-vocabulary 2D segmenter with refined prompts, cross-entropy weight 0.05. No separate depth loss.

**Results that matter**: Occ3D-nuScenes mIoU 10.81 (9.53 on the original definition); nuScenes depth Abs Rel 0.202 / RMSE 6.697 for the full model against 0.627 / 15.901 for colour-difference supervision only; contraction + resampling brings Abs Rel 0.216 -> 0.202. Semantic prompts: SAM logits 7.50, raw names 8.23, full 10.81 mIoU. Compute: 8 A100, 128 min per epoch (SurroundOcc 75), single A100 inference 0.18 s and 11.0 GB. Rendering is not needed at inference.

**Transferable technique**: photometric self-supervision with auto-masking for a depth-like auxiliary; coordinate contraction so a bounded BEV volume still serves far rays; predicting the rendering weight directly instead of density.

**Cost and fit**: heavy (inference 0.18 s on A100 is not "very fast" for a 3060); photometric-only quality is poor (mIoU 10.8 against 20-30 for supervised). Dynamic objects break photometric consistency.

**Doubts**: rays per image not stated; ablation checkmarks unclear; comparisons with SelfOcc are on the same weak scale.
