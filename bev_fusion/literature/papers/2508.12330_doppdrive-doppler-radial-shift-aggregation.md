**What it does**: Preprocessing before any detector. An earlier-sweep point p_k is first moved to the current frame by the ego motion, then shifted along its own radial direction by its dynamic Doppler: q = p + v * u_hat * (T0 - Tk), with v = d - h (measured Doppler minus the ego-speed component h = cx sin(theta) + cy cos(theta)); static points (zero dynamic Doppler) do not move. Because the Doppler tells only the radial speed, the unknown tangential smear grows with the elapsed time: expected tangential offset |v| (T0 - Tk) g(theta) with g(theta) = E over heading of tan(theta + alpha) (Laplace heading prior, b = 3.1); a point is kept only if (T0 - Tk) <= D / (|v| g(theta)), tolerance D = 2 m. So each point gets its own aggregation window, long for static and radial-slow points and short for fast points near the side of the sensor.

**Results that matter** (vehicle AP, BEV IoU 0.1; checked): with the SMURF detector - aiMotive: no aggregation 74.6, standard fixed window (<= 0.7 s) 81.7, DoppDrive 89.1; LRR-Sim 89.2 / 91.1 / 93.3, beyond 175 m 61.2 / 63.1 / 69.2. Ablation: radial compensation and the non-fixed window each add; point elimination removes about 11 % of dynamic points and is worth about 3.9 AP. Cost (SMURF, V100): aggregation 2.0 ms vs 1.4 ms, total 69.5 ms vs 69.2 ms. Other detectors tested: Radar PillarNet, Nvradarnet, K-Radar. Not tested on nuScenes or VoD.

**Transferable technique**: for the multi-sweep radar image: shift each old detection by v_dyn * u_original * dt (radial only), and give it an uncertainty that grows tangentially with dt * |v| * tan(theta) (the polar footprint widening in azimuth = the dt-widened sigma_phi in radar_encoding.md section 5). With known ego velocity the dynamic Doppler is a closed form, no network.

**Cost and fit**: a few array operations per point (2 ms for thousands of points on a V100, our case far fewer); no learnable weights.

**Doubts**: no nuScenes numbers; datasets are higher-resolution long-range radars; AP at IoU 0.1 is very loose; dynamic Doppler needs a good ego velocity and the sensor-frame ray; heading prior (Laplace) fitted on the authors' data.
