**What it does**: Input is the complex range-Doppler spectrum of 16 receivers, real and imaginary stacked (512 x 256 x 32 in the appendix). A MIMO pre-encoder (atrous 1 x N_Tx convolution + 3 x 3) and a residual FPN encoder (blocks of 3, 6, 6, 3 layers) feed a range-angle decoder that swaps the Doppler axis for azimuth and deconvolves only the range axis. Heads: detection on a coarse polar map of 0.8 m x 0.8 deg cells (a sigmoid occupancy map + a 2-channel regression of range and azimuth offsets), and free space on a 0.4 m x 0.2 deg map within +-45 deg.

**Supervision / distribution**: vehicle position is a binary per-cell target plus a paired range / azimuth offset regression (no Gaussian blob, no predicted variance, as far as the page shows). Loss: focal (gamma 2) over all cells + beta * smooth-L1 on positives (beta = 100), + lambda * BCE for free space (lambda = 100). Adam 1e-4, 100 epochs.

**Results that matter** (RADIal test split, IoU 0.5): AP 96.84 %, AR 82.18 %, range error 0.11 m, angle error 0.17 deg; Pixor on RA input 96.56 / 81.68, Pixor on the point cloud 96.46 / 32.32 (recall). Free-space mIoU 74.0 % vs 60.6 % for PolarNet. 3.79 M parameters, 584 GFLOPS; runtime not reported on the page.

**Transferable technique**: the target design: a polar cell grid with a coarse cell (here 0.8 m, 0.8 deg) and a continuous offset regressed inside the cell is the discrete + residual position code (categorical over bins + offset), the simplest parameterisation of a position distribution that is learned from a hard label. Recall 82 % vs 32 % for the same detector on thresholded points shows what is lost when the radar is reduced to points.

**Cost and fit**: 584 GFLOPS is far above a few-ms budget on the 3060; the raw ADC / RD data do not exist for nuScenes (it has processed 2D+1D detections).

**Doubts**: one dataset, one vehicle class, a 70 / 15 / 15 split in which no sequence is shared across splits; no uncertainty output; no runtime on the page.
