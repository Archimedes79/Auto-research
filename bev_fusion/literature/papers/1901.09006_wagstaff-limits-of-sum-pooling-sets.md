# 1901.09006 On the Limitations of Representing Functions on Sets: the pooled latent must be at least as wide as the set

**What it does**: Studies functions of a set computed as rho(sum_x phi(x)) (Deep Sets). Theorem 4.4 (checked): a continuous permutation-invariant function on sets of at most M scalars is continuously sum-decomposable through R^M; Theorem 4.1: for N < M some continuous permutation-invariant functions are NOT decomposable through R^N, so N >= M is necessary in general. Simpler functions (the mean) can use a smaller latent. Discontinuous constructions can do better but a network cannot represent them. A similar statement holds for max-pooling (Lemma 4.2, Theorem B.1). The theorems are for scalar elements; no result for D-dimensional elements is given on the page.

**Results that matter** (checked): one toy experiment, predicting the median of a set with a 3-layer-before / 2-layer-after sum architecture (1000 ReLU units, 500 batches, 500 seeds): the error drops with the latent size N and plateaus at a critical N that grows about linearly with the set size M but lies below M; out of distribution (N = 100, M = 500) an all-ones input gives 0.933 instead of 1.0 and 200 ones with 300 zeros gives 0.413 instead of 0.0.

**Transferable technique**: pooling the per-detection embeddings of a cell with mean / sum / max into one vector is lossless for the set only if the vector is at least as wide as the number of elements times what each element needs (for scalars: N >= K). With K <= 3 detections of about 40 values each the pooled vector would have to be of the order of K x 40 anyway; storing K explicit slots (sorted, with a count) uses the same width without asking a network to learn an injective code, and a probe is easy to build (regress slot j's attributes from the cell feature). Mean pooling plus count is not injective for two detections (two detections with Doppler 1 and 3 m/s and with 2 and 2 m/s give the same mean and count); from memory (Newton identities, not from this page), K power sums determine K scalars, which is why mean + second moment + count separates two.

**Cost and fit**: nothing to implement.

**Doubts**: scalars only; the toy task is the median, not a reconstruction; the "critical N below M" result shows trained networks can do with less than the worst case, so the bound is a worst case, not the typical need.
