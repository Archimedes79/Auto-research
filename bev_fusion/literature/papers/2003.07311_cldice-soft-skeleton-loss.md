**What it does**: clDice = 2 Tprec Tsens / (Tprec + Tsens) with Tprec = |skel(P) within G| / |skel(P)| and Tsens = |skel(G) within P| / |skel(G)|. Differentiable by a soft skeleton: iterated min-pool (erosion) / max-pool (dilation), k iterations with k >= the largest tube radius (paper uses 5-25). Loss L = (1 - a)(1 - soft Dice) + a (1 - soft clDice), a in [0, 0.5], tuned per dataset. The skeleton is computed on the PREDICTION at every step.

**Results that matter** (Table 1, Dice / clDice / beta1 error): Roads U-Net soft Dice 76.23 / 86.83 / 1.256 -> a = 0.5 76.45 / 88.17 / 0.953; Roads FCN 64.84 / 70.79 -> 67.18 / 76.92 (a = 0.4); DRIVE U-Net 74.25 / 75.71 -> 75.21 / 76.86; CREMI and synthetic vessels gain least. Runtime batch 4, 1024x1024, RTX 8000: 1.35 s against 1.24 s per batch (< 10 %) in the paper, whereas the later Skeleton Recall paper measures +88 % time on nnU-Net (different pipelines).

**Transferable technique**: for 1-3 cell lines the soft skeleton is nearly the identity at k = 1; the mechanism only matters for wider layers (centre-line bands, drivable-area strips at junctions). Using the soft skeleton on predictions also gives a "skeleton-precision" term that Skeleton Recall lacks.

**Cost and fit**: O(k n^2) per image, extra ops on the full BEV map per step; adds a sensitivity (k, a) per layer. Binary 2D / 3D theory only; the authors state multi-class is untested. No soft-label or ignore-mask handling (we would multiply by the cell weight inside the pooling window, which smears masks).

**Doubts**: Dice sometimes falls at high a (DRIVE FCN 78.23 -> 77.76); the soft skeleton is a proxy; gains small on easy data; no registration-noise or dashed-structure experiment.
