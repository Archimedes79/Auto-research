## 1. Card text
- **Statement:** In the champion token head, reading the wiring after layer 1 (arms x, r1) and after layers 1 and 2 (arm r2) and letting the tokens exchange information along the read connections before the next layer raises the VAL topo F1 at the D115 decode by at least the band 0.010 over the retrained champion head on both seeds, without lowering F1@1.0, lanes found or junction F1 beyond the guards; the loss on the early reads (r1 over x) and the second round (r2 over r1) each have to earn their place against the simpler arm (section 1.3).
- **Mechanism:** Today the wiring is read once, after layer 3, and supervised once; before that the tokens exchange information through self-attention over all tokens with a relative-geometry bias, which knows nothing about who the likely partners are (no token sees its likely successor or predecessor before the final read). A round reads the wiring from the current features (the same function as the final read, shared weights, so a read has the meaning "who is my successor"), and passes to every token a weighted sum of the features of its likely successors and of its likely predecessors; the next layer then attends with that information. With the loss on each early read the connection structure is supervised from the first round on (deep supervision with one shared reading, as the head does for the types: one `types` linear for both positions); without it (arm x) the early read is only a learned weighting that the final loss shapes through the messages. All steps are soft: the message weights are the early read probabilities themselves (no argmax, no threshold, no new hard selection); R1 stays met up to the named items. Precedent: CGNet re-predicts and supervises the adjacency in every decoder layer with one shared head and message passing along A and its transpose, TOPO 39.6 / 41.3 / 42.2 for 1 / 3 / 6 rounds, the head adding 0.3 of 241.9 GFLOPs (E355, closest designs): a gain of about 4 % relative from one to three rounds, against our band of 0.010 on 0.67 (1.5 %); a different task and size, the size of the effect is not transferred.

### 1.1 The change in detail (the design the coder is given, with `DESIGN.md`)
- **Option `--rounds R` (0, 1, 2; default 0 = the champion):** a round after layer 1 (R >= 1) and after layer 2 (R = 2). In a round k, from the current features x:
  1. **early read:** the wiring is read with the SAME function as the final read (`lnw`, `wq`, `wk`, `wbias(g)`, `dest`, `none_k`, `none_b`; shared weights), key weight `lw(w1)` after the switch step and `lw(w_in)` before it (the key weight the layers use); `wbias(g)` is computed once and reused. Output `logp_k` (B, 2, K, K + 1), same shape and masks as `logp`;
  2. **exchange:** p_k (B, K, K) = the sum over the two classes of exp(`logp_k`[..., :K]) x gate, the early probability of the link i -> j. Forward message `mf_j = sum_i p_k[i, j] (W_v x_i)`, backward message `mb_i = sum_j p_k[i, j] (W_u x_j)`; `x <- LayerNorm(x + MLP([mf ; mb]))` (MLP 128 -> 64 -> 64, GELU), parameters of each round separate (about 20 900 each, +16 % of the head's 127 131 per round); p_k is not detached (the final loss reaches the early read through the messages);
  3. the next layer runs on the updated x. The type reads (`types1` after layer 1, `types` after layer 3), the key weights w1 / w3 and the final read are as today.
- **Option `--wire-weight W` (default 0):** the early loss `W x sum_k (nll_k_s + nll_k_l)` with `_source_nll` on `logp_k`, with the same none weight, rows and normalisation as the final likelihood; W = 0.5 (the weight the layer-1 type cross-entropy has), ONE value, not tuned. With W = 0 the early reads get no loss (arm x). Info keys `nll1_s`, `nll1_l`, `nll2_s`, `nll2_l`.
- **Option `--msg uniform` (the content null u):** the message weights replaced by uniform weights over the allowed pairs that keep each token's soft degree: `w_fwd[i, j] = gate[i, j] / sum_i' gate[i', j] x indeg_j`, `indeg_j = sum_i p_k[i, j]`, and `w_bwd[i, j] = gate[i, j] / sum_j' gate[i, j'] x outdeg_i`, `outdeg_i = sum_j p_k[i, j]`: the same parameters, row sums and pooling as the real exchange, but no information about WHICH neighbours the early read found likely (uniform weights without the degree scale would differ in scale and sparsity and make the comparison pass by construction).
- **Eval mode:** with `--rounds` >= 1 the early reads and the exchange run in eval mode too (they are part of the forward); with `--rounds 0` the forward, the loss and the parameters are the champion's bit for bit.
- **Not changed:** the allowed-pair gate, top-K, the four read-out thresholds, the type softmax, the scale branch, the data, the caches, the decode.

### 1.3 The verdict (by hand, written before any run; the JSON rule is NOT the verdict)
D_X(S) = topo F1(X_sS) - topo F1(c_sS) at D115 on VAL 873, per seed; the paired scene-bootstrap 95 % interval of D comes from the paired card. The first that applies, in this order:
1. **INCONCLUSIVE:** a kill fires; a started run does not finish (a seed 1 skipped by the early stop is not this case: CUT covers it); the two seeds disagree beyond the band (one D >= +0.010, the other <= -0.010); on exactly one seed a guard fails while D >= +0.010. Add the diagnosis (a seed), no verdict.
2. **CUT-X:** D <= -0.010 on one seed and the other seed not >= +0.010 (or not run); or a guard fails on both seeds.
3. **KEEP-X (quality):** D >= +0.010 on both seeds, the 95 % interval of D excludes 0 on both seeds, and the guards hold on both seeds: F1@1.0 not below c by more than 0.005, lanes found by more than 0.010, junction F1 by more than 0.015.
4. **TIE:** everything else; the simpler arm wins (c over x over r1 over r2).

All arms share c_s<S>: a lucky or unlucky c moves every arm against c in the same direction, the arm-to-arm steps of the ladder cancel it.

## 2. Detail plan (block experiment)
What would make it fail, in plain words: (i) layer 1 has seen only one attention layer, its wiring read may be too poor to supervise usefully, and the early loss then pulls layer 1 toward a task it cannot do (CUT or TIE; the weight 0.5 is one untuned value; arm x is the check); (ii) messages over bad early edges spread errors (an early edge with p near 0 sends no message, so false negatives are not amplified, false positives are); (iii) the shared reading may need different statistics at layer 1, 2 and 3 (the types share one reading without visible harm; a separate early reading would cost parameters, not tried); (iv) layers 2 - 3 may already compute what a round adds (attention is a soft edge matrix); the ladder is the probe; (v) the gain may sit inside the noise band, as most head-side changes of E367 - E388 did.
