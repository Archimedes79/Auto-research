## 1. Card text
- **Statement:** a head whose cross-attention output is FUSED with the token by a gated MLP that sees the attention evidence decides weak tokens better than the same head without the block: topo F1 +0.004 (window -0.002 to +0.010) over the matched control z on VAL, both seeds, stream mode, each arm at its own pinned cell and at the common cell.
- **Mechanism:** the E368 block adds W_o(attn) to every token: where the past holds nothing near the token the attention goes to the none key and the added vector is a constant; where it holds a duplicate or a wrong neighbour the added vector is noise that the FFN then has to undo. The fusion sees (i) LN(x), the token as the head built it, (ii) LN(c), what the past says, (iii) a = the attention mass on REAL past keys per head (1 - the none mass: how much the token found in the past at all) and (iv) the attention-pooled cross-geometry (turn, offset along / across the token's heading, distance, existence of both): is the found past token where the token expects its predecessor? A per-token gate g = sigmoid(Linear(...)) with a negative bias passes x unchanged where the past does not help.
- **The module (`training/grid/jpast.py`, `FusedPastBlock(PastBlock)`):** the attention part is E368's (pre-norm queries and keys, 4 heads of 16, the learned none key per head, the geometry bias MLP(7 -> 32 -> H), + log(w_j + 1e-3), padding masked); `PastBlock.attend` became `attend_g` (returns the pair geometry g as well, computed once) with `attend` as a wrapper, the value mixing is one helper `mix`. The output projection `o` is at its ORDINARY initialisation (`o.reset_parameters()` after the `PastBlock` init, which zeroes it): c = o(attended values) is a live signal and the zero-init moves to the MLP output, so that o and the MLP do not both start dead. Per valid token: `a` (B, K, 4) = per head 1 - the none mass; `gp` (B, K, 7) = sum over the real keys of the head-mean attention weight x the 7 geometry features of the pair (**deliberately NOT divided by the real mass: dividing by a mass near 0 is unstable, the mass `a` is an input next to it**); `feat = [LN_x(x), LN_c(c), a, gp]` (64 + 64 + 4 + 7 = 139); `y = W2 GELU(W1 feat)` (139 -> 64 -> 64, **W2 weight AND bias zero**); `g = sigmoid(w_g feat + b_g)` (**b_g = -2.0 exactly, w_g ~ N(0, 0.02^2)**: the gate starts at 0.119 on average, within 0.02 over random features; it gets no gradient until W2 moves); output `x + g * y * valid`, padding queries keep x. **`delta` is overridden** (`PastBlock.use` and the `UseMeter` take the update as out - x and compare it with `self.delta(...)`: an inherited delta would give a meaningless u; a mutant tests it). A first frame / an all-invalid past: the softmax has the none key only, a = 0, gp = 0, c = the none value through o. **Parameters: 17,416 (attention part, as E368) + 2 x 128 (LN_x, LN_c) + 8,960 + 4,160 + 140 = 30,932 (+13,516 over E368's block; +0.031 M over the 127,131 of the head, +24 %), pinned in the selftest** (the critic and the hook owner recounted it). The code was reviewed by the hook owner (ACCEPT, no blocking finding) before this card was fixed; a separate code critic pass follows the restore.
