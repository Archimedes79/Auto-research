**What it does**: View-of-Delft 4D radar, single sensor. Per point: range, azimuth, elevation, RCS, relative radial velocity v_rel and the ego-compensated radial velocity v_r. With beta = arctan(y/x) the compensated velocity is split into v_r,x = cos(beta) v_r and v_r,y = sin(beta) v_r, and the same for v_rel; the pillar mean velocity is subtracted as offset features. So the ray direction enters the point feature through the cos / sin of the azimuth multiplying the Doppler. A PointNet layer builds pillar features (320 x 320 grid), then PillarAttention (self-attention over the occupied pillars only, one pillar = one token, no position embedding, LayerNorm + 2-MLP GeLU FFN), then a 3-stage 2D CNN with a constant width C = 32, transposed-conv neck, SSD head. Timestamp is not a feature; frames are accumulated with the trajectory (1 / 3 / 5 frames).

**Results that matter** (VoD val, mAP over car AP50 / ped AP25 / cyc AP25, fact status checked): 1 frame, entire area: RadarPillars 46.0 vs re-implemented PointPillars 39.5; driving corridor 67.3 vs 60.9. 5 frames: 50.7 entire area / 70.5 corridor (SMURF 5 frames 51.0 / 69.7). Radar-only 1-frame baselines in the paper (entire-area mAP): PV-RCNN 43.6, Voxel-RCNN 36.9, SECOND 33.2, PillarNet 23.7, MVFAN 39.4. Ablations (entire area, PointPillars base 39.5): decomposed compensated velocity 43.3 (+3.8, the largest single step); dropping v_r as a feature costs 7.2, dropping v_rel 0.9; attention variants (Table III) point-attention 40.6 / 41.6 masked, feature-attention 41.3, pillar-attention 42.9; uniform width C = 64 gives 42.6 and C = 32 42.0 (0.26 M parameters) against 4.84 M for the doubling PointPillars. Cost: 0.27 M parameters, 1.99 GFLOPs (PointPillars 4.84 M, 16.46), 1-frame 86.6 Hz on a V100, 184.5 Hz on an RTX 3090 (about 5.4 ms for the whole network), 34.3 Hz on an AGX Xavier. Text and Table III disagree on the attention gain (+1.6 in the text, +3.4 in the table); C = 32 rate is 36.1 Hz in Table V and 34.3 in Table I.

**Transferable technique**: (1) put the ray direction INTO the Doppler feature (cos / sin of the azimuth times v_r) - this is the closest published relative of our circular ray + Doppler code, and it is worth more than any attention variant tested (+3.8 vs +1.1 to +3.4); (2) narrow and constant channel width (32) beats the standard doubling pyramid; (3) the attention is cheap only because it runs on occupied pillars, 125-point radars give about 100 tokens per sensor.

**Cost and fit**: 5 ms-class on a 3090; attention on occupied pillars only. 5 radars of 125 points: a few hundred tokens, trivially small. Needs elevation and z (4D radar); nuScenes has neither (z = 0), so the pillar grid is 2D anyway.

**Doubts**: VoD is 4D radar with elevation and much denser detections than nuScenes 2D radar (125 / sweep cap); the attention ablation is on the weak PointPillars base, measured entire-area only; no seeds; text / table inconsistencies above; no code, so the numbers cannot be reproduced.
