Decision: D72 (Mirko, in chat on 2026-11-10, in the BEV system chat; I had asked whether the Evaluation chat should also build a run of the network without the ground truth; his words, verbatim: "Ja, bauen lassen, aber als separate Klasse, die von der Eval Klasse aufgerufen wird."). My reading, which he can correct: (1) a run of the trained network that reads no ground truth and computes no validation loss is built; (2) it is its own class (a `Runner`: `run(network, frames)` -> the stored predictions), not a mode inside the Evaluation class and not a second Subject hidden in the adapter; (3) the Evaluation class calls it (`Evaluation.predict` / `run` delegate the running to it, as in his sketch `Evaluation.run(runner, network, ...)`), so the Runner can also be used alone, for testing a network without labels, and its stored predictions can be scored later by `Evaluation.score` when a ground truth exists; (4) it keeps what is decided already: always warm and whole scenes (D70), the same stored format and identity as `Evaluation.predict`, taps on request, the memory check; (5) it is built by the Evaluation chat (the owner of `evalsuite/`), on the Network-based draft in `bev_fusion/temp/cleanup/runner_draft/` if it helps, without editing the frozen `bev_adapter.py` / `bev_runner.py`; the name must not clash with `runsuite.Runner` (the job layer of the Training chat): the two chats settle the name.
Consequence: the Evaluation chat builds the class (`evalsuite.Runner`, `evalsuite/runner_api.py`; `Evaluation.predict` / `run` delegate to it); the BEV side (`evaluation/bev_free.py`: `FreeSource`, `FreeSubject`) is built and its outputs are bit-equal to the live subject's on real frames (c4c6b8b26b, tests/test_bev_free.py). **What Mirko loses by it:** a run without the ground truth has no validation loss, so `loss.*` and `val_loss/*` are no longer part of the numbers and cards of `Evaluation` (told by the Evaluation chat); `bev_suite.py eval` keeps them. `bev_fusion/records/jobs/evaluation/README.md` loses its "GT-free predict is open" note when the class is in.
