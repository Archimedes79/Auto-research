# TP22 - TopoGPT (generative lane graph with map pre-training)

*Pass: loop 16 (2026-10-23), cluster `topology` (lane topology heads, link scoring, graph priors). Reading depth: **M** (A abstract, M method, C code page). Verified: checked. Pipeline stage: S6 T X.*

## Papers

Generative Lane Topology Reasoning via Autoregressive Model with Geometry Prior (TopoGPT, Fu et al., ECCV 2026, arXiv 2606.31814) https://arxiv.org/abs/2606.31814

## Idea

Lanes become tokens (each lane a cubic Bezier = 4 control points, each control point one joint (x, y) bin index), the lane set is sorted and generated by a decoder-only transformer pre-trained on 3.3 M map-only scenes; a flow-matching adapter aligns BEV tokens to the scene-token space for the camera version.

## Formulation

Q(v) = floor(v / vmax (N_bins - 1)) + 1 with N_bins = 64 over the BEV range; token tau_i = Q(y_i) N_bins + Q(x_i); lanes sorted by [xmin, ymin, xmax, ymax]; tokens <SOS>, <SEP>, <EOS>; sequence 5M + 1 tokens for M lanes; lanes split at forks and merges so the graph is implied by shared endpoints; edges at inference from a 0.5 m endpoint-distance threshold. Pre-training data: Waymo Motion 2.07 M, nuPlan 1.01 M, Argoverse 2 Motion 0.25 M scenes; teacher forcing, cross-entropy; model sizes 24.7 / 45.9 / 91.3 M. Adapter: ResNet-50 BEV encoder, DiT predicting a velocity field (flow matching), L_align MSE to the frozen scene tokens, LoRA on the decoder; greedy decoding, Euler integration of the adapter ODE (6 steps best).

## Input

rasterised lane image (pre-training) / BEV tokens (fine-tuning) as a prefix.

## Output

token sequence -> Bezier lanes -> graph.

## Training

pre-training 16 epochs on 8 H20; fine-tuning 24 epochs.

## Differentiable?

no - discrete tokens, greedy decoding; adapter flow is differentiable.

## Sensors and data

camera; OpenLane-V2 A and B; range +-52 x +-32 m, 64 bins.

## Reported results

subset A lane-level M-P / M-R / M-T 45.6 / 42.6 / 24.4 (best prior TopoPoint 42.7 / 34.0 / 16.6); point-level G-F1 60.3, T-F1 47.4, JT-F1 35.7, APLS 28.7; subset B 43.1 / 39.2 / 23.4. Ablations: from scratch 7.4 / 7.0 / 0.8; frozen 44.3 / 42.1 / 23.7; LoRA 45.6 / 42.6 / 24.4; pre-training augmentations none 41.0 -> both 45.6 (M-P).
