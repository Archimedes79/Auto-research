## 1. Card text
- **Statement:** In the champion token head, (a) a second read of the wiring after layer 1 with its own successor likelihood, (d) in addition the degree of every token in the early edge set as two scalars, and (b) in addition one message pass along the soft early edges, each followed by the unchanged layers 2 - 3 and the final read, raise the VAL topo F1 at the D115 decode by at least the band 0.010 over the retrained champion head on both seeds, without lowering F1@1.0, lanes found or junction F1 beyond the guards, and with each step beyond a earning its place against the simpler arm (section 1.3).
- **Mechanism:** Today the wiring is supervised once, at the end; layer 1 is supervised only through the node types (`ce1`). (a) is deep supervision with a shared reading, as the head already does for the types (one `types` linear for both positions): layers 2 - 3 get a gradient on the connection structure earlier; a training-time change (no new parameter, and in eval mode no early read at all). (d) tests the narrow claim directly: a token with two soft successors is a fork, with two soft predecessors a merge, with neither an entry or an exit; two scalars carry exactly that, at 192 parameters. (b) is the wider claim: a token reads the features of its predicted neighbours (messages along p1 and its transpose); it would matter if more than the degree helps (a neighbour's type, direction, spacing). The three are a ladder, each rung simpler than the next. All steps are soft: the message weights and the degrees are the early probabilities themselves (no argmax, no threshold, no new hard selection); R1 stays met up to the named items. Precedent: CGNet re-predicts and supervises the adjacency in every decoder layer with one shared head and message passing along A and its transpose, TOPO 39.6 / 41.3 / 42.2 for 1 / 3 / 6 rounds, the head adding 0.3 of 241.9 GFLOPs (E355 section on closest designs); a different task and size, so the size of the effect is not transferred. E357 (a pair head with independent edges, without node types and without the one-successor structure, over-produced the links by 1.2 for lane links and 15 for junction links) shows that structure matters, not that this mechanism helps.

### 1.1 The change in detail (the design the coder is given, with `DESIGN.md`)
- **Order inside the head:** layer 1 -> `types1, w1` read from this x (unchanged) -> the early wiring read from the same x -> [arm d: the degree scalars; arm b / u: the message update] -> layers 2 - 3 (key weight `lw(w1)` after the switch step, as today) -> `types`, the final wiring read as today.
- **Early read (a, d, b, u):** with the SAME projections and bias as the final read (`lnw`, `wq`, `wk`, `wbias(g)`, `dest`, `none_k`, `none_b`; one reading for both positions, as for the types), key weight `lw(w1)` after the switch step and `lw(w_in)` before it. `wbias(g)` is computed once and reused. Output `logp1` (B, 2, K, K + 1), same shape and masks as `logp`. **In eval mode arm a computes no early read** (its forward is the champion's bit for bit); d, b and u need it in eval mode as well.
- **Early loss (a, d, b, u):** `wire1_w x (nll1_s + nll1_l)` with `_source_nll` on `logp1`, with the same none weight, rows and normalisation as the final likelihood; `wire1_w` = 0.5 (the weight the layer-1 type cross-entropy has), ONE value, not tuned. Scale and type terms unchanged. At `wire1_w` 0 and `msg` none the loss, the forward and the parameters are the champion's.
- **Arm d (degree):** p1 (B, K, K) = the sum over the two classes of exp(`logp1`[..., :K]) x gate; in-degree `sum_i p1[i, j]` and out-degree `sum_j p1[i, j]` (B, K, 2); `x <- x + Linear(2 -> 64)(deg)`, weights zero-initialised (192 parameters; the head starts as the champion).
- **Arm b (message pass):** forward message `mf_j = sum_i p1[i, j] (W_v x_i)`, backward message `mb_i = sum_j p1[i, j] (W_u x_j)`, `x <- LayerNorm(x + MLP([mf ; mb]))` (MLP 128 -> 64 -> 64, GELU). No degree normalisation (the arm d isolates the degree). p1 is not detached. About 20 900 parameters (+16 % of the head's 127 131); about 2 x K x K x 64 = 33.5 M MACs on a head of 0.86 GMACs; the second read adds the q.k einsum and one softmax over (B, 2, K, K + 1); the measured time decides, not the MACs.
- **Arm u (content null, only when b qualifies; scale-matched):** b with the message weights replaced by uniform weights over the allowed pairs that keep each token's soft degree: `w_fwd[i, j] = gate[i, j] / sum_i' gate[i', j] x indeg_j` with `indeg_j = sum_i p1[i, j]`, and `w_bwd[i, j] = gate[i, j] / sum_j' gate[i, j'] x outdeg_i` with `outdeg_i = sum_j p1[i, j]`: the same parameters, the same row sums and the same pooling over the gate as b, but no information about WHICH neighbours the early read found likely. (Uniform weights without the degree scale would differ from b in scale and sparsity and make b - u pass by construction.)
- **Not changed:** the allowed-pair gate, top-K, the four read-out thresholds, the type softmax, the scale branch, the data, the caches, the decode.

### 1.3 The verdict (by hand, written before any run; the JSON rule is NOT the verdict)
D_X(S) = topo F1(X_sS) - topo F1(c_sS) at D115 on VAL 873, per seed; the paired scene-bootstrap 95 % interval of D comes from the paired card. The first that applies, in this order:
1. **INCONCLUSIVE:** a kill fires; a started run does not finish (a seed 1 skipped by the early stop is not this case: CUT covers it); the two seeds disagree beyond the band (one D >= +0.010, the other <= -0.010); on exactly one seed a guard fails while D >= +0.010. Add the diagnosis (a seed), no verdict.
2. **CUT-X:** D <= -0.010 on one seed and the other seed not >= +0.010 (or not run); or a guard fails on both seeds.
3. **KEEP-X (quality):** D >= +0.010 on both seeds, the 95 % interval of D excludes 0 on both seeds, and the guards hold on both seeds: F1@1.0 not below c by more than 0.005, lanes found by more than 0.010, junction F1 by more than 0.015.
4. **TIE:** everything else; the simpler arm wins (c over a over d over b).
- **The ladder (each rung must earn its place against the best simpler arm that is KEEP; if no simpler arm is KEEP the comparator is c and KEEP-X is already the whole test):** if a is KEEP, d needs d - a >= +0.010 on both seeds; b needs b - (the better of a and d among those that are KEEP) >= +0.010 on both seeds; otherwise TIE and the simpler KEEP arm stands. So a gain of b that the early loss or the degree already give does not adopt b. The ladder, the u test and the guards use point differences; only KEEP-quality uses the 95 % interval. All arms share c_s<S>: a lucky or unlucky c moves every arm against c in the same direction, the arm-to-arm steps of the ladder cancel it.
- **The capacity null (content, not scale):** only when b is KEEP-quality and passes the ladder, u is run on both seeds; b is adopted only if b - u >= +0.010 on both seeds (which neighbours a token reads, not the extra block and not the degree, carries the gain); otherwise TIE.
- **Cost (arms d and b; arm a has none at inference):** `jtoken_eval.py timing --run e392_<arm>_s0 --b-run runs/e292_a_s0` (24 cached VAL frames, batch 1, bf16, quiet GPU, `usable_for_gcost` true) for c, d and b in the same session: KEEP needs head(X) <= head(c) + 1.0 ms and the whole path <= 19.7 ms; otherwise **QUALITY-ONLY** (reported, not adopted). The 19.7 ms is the E365 G-cost bound (E324 s); the +1.0 ms (about 6 % of the 16.2 ms path) is this card's own bar, chosen here, not taken from a source.
- **Scope:** a KEEP replaces the stage-1 recipe only; the champion S4 changes in a follow-up card; nothing here touches TEST or the champion entry.

## 2. Detail plan (block experiment)
What would make it fail, in plain words: (i) layer 1 has seen only one attention layer, its wiring read may be too poor to supervise usefully, and the early loss then pulls layer 1 toward a task it cannot do (CUT or TIE; the weight 0.5 is one untuned value); (ii) a message pass over bad early edges spreads errors (an early edge with p near 0 sends no message, so false negatives are not amplified, false positives are); (iii) the shared reading may need different statistics at layer 1 and layer 3 (the types share one reading without visible harm; a separate early reading would cost parameters and is not tried); (iv) layers 2 - 3 may already compute what d and b add (attention is a soft edge matrix); the ladder is the probe: if d and b are not above a, they add nothing; (v) the gain may sit inside the noise band, as most head-side changes of E367 - E388 did.
