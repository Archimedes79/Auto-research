# training - the system (models, data, losses, training, inference)

Long-lived code of the lane-graph chain. All modules are imported flat (`import p16_builder as PB`); the launcher `tools/env/_py14.sh` puts every folder on `PYTHONPATH`, so a module can move between the folders below without breaking imports. **New model code goes here; one-off analysis does not (that is `temp/`).**

> **System of record (D113 - D120): the token champion.** Frozen GaussianCaR features -> the frozen lane head B' (`grid/qgraph.py`, `grid/pyramid.py`) -> its predicted nodes as tokens (`data/lane_tokcache.py` cached, `data/lane_live_tok.py` live) -> the token head (`grid/jtoken.py`) -> a read-out by four named thresholds (`../evaluation/jtoken_eval.py`); trained in two stages (`train/jtoken_train.py`, then `train/jlive_train.py`). The drawing is `architecture.svg` / `.md`, the modules and rules are in `../DESIGN.md`. The route-association head of E389 (`grid/jroute.py`, `train/jroute_train.py`, `data/lane_route_data.py`) is a separate measured stage (TIE), not part of the delivered chain.

> **Reference system (D89, 2026-11-13): kept, marked, not developed.** The route-graph chain of loops 8 - 18 (`p8_*` / `p10_*` / `p13_*` - `p18_*`: builder, route heads, junction head, assignment, map registration, the loop-16 pipeline and `p16_*` / `p17_*` / `p18_*` drivers and trainers, `grid/chain*.py`, `train/dense_head.py`) stays in the tree so that the prototype of record (`recall_sp0_dp`, TEST 0.740) and the E272 chain can be re-scored and compared (`evaluation/evaluate.py`, `vertex_eval.py run_ref`). **New work does not build on it:** the lane head of E273 and later (`grid/`, `train/qgraph_train.py`, `jends` / `jmaps`) is the system; the reference system gets bug fixes only. Its removal is decided: D97 (2026-11-14) chose option B of D89 (decouple the scorers, then remove it, in steps; D93, D129): the files outside the import closure of `evaluation/evaluate.py` were removed on 2026-11-21 (commit 4a8b538b), what remains stays until the scorers no longer import it, and afterwards it is only in the git history.

## Ground rules
- Everything that trains must be resumable and must write `log.txt` / `train.log`, `log.jsonl`, `config.json`, `status.json`, `model.pt` into `runs/<name>/` (use `trainer.fit`: that is the Training contract).
- Metrics are not defined here - call `evaluation/` (`sparse_lanes`, `lane_grid`).
- Cached foundation features are read from the WSL home (`~/exp_gcar_b123`, `data/README.md`); nothing here writes there except `prep/`.
- Speed is a criterion: a change of the pipeline keeps the graphs identical (`evaluation/drivers/p16_fast_check.py`).
