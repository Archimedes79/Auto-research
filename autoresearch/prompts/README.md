# prompts

The texts a lead chat is started with. They follow `../METHOD.md`.

| file | what |
|---|---|
| `research_steps.md` | step 0 (start of a round), P1 research on a trigger, P2 branches, run by hand step by step |
| `loop.md` | the inner loop P3 and the close P4, pasted after `/loop`; the filled copy of a loop is kept in the problem's history |
| `experiment_flow.md` | one experiment in six steps: card, coding, experiment, training, evaluation, result folder |
