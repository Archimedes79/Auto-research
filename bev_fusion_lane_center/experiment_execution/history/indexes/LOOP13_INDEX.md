Process lessons: `pkill -f` with a pattern that occurs in your own command line kills your own shell (use `pkill -f "[p]attern"` and make sure the plain pattern does not occur elsewhere in the command); a learned baseline that gets only a zero token and tiny-scale ego features did not train (3.05 m everywhere): standardise the inputs and check a learned baseline against the analytic one; heredocs inside `wsl bash -c '...'` break on quotes (write a patch file); a `done` flag written by a wrapper after a killed run is spurious (check the DONE line of the log); a 'tok_*_oof*' file name does not mean out-of-fold tokens (only the dense-head inputs were out-of-fold; the review caught the wrong claim); reviewers found, in two rounds, wrong ranges, many-to-one against one-to-one matching, pooled against unweighted means, unmarked readings and a wrong 'out-of-fold' statement: run them before delivering.
