**What it does** [checked]: depth bins by linear-increasing discretisation (LID), d_c = d_min + (d_max - d_min) / (D (D+1)) * d_i (d_i + 1), plus one out-of-range bin that enters the depth loss but is dropped from the frustum. ResNet-101 Block1 features (stride 4, 256 reduced to 64 channels) and a DeepLabV3-style head give a per-pixel softmax depth distribution. Frustum grid G(u,v) = D(u,v) outer F(u,v), shape W_F x H_F x D x C. Voxel centres (X x Y x Z) are projected with the camera matrix P into the frustum, depth converted to bin index, G is sampled trilinearly to V in R^(X x Y x Z x C); Z is folded into channels and a 1 x 1 conv + BN + ReLU gives the BEV map B in R^(X x Y x C). Detection head: PointPillars-style, deeper blocks (10, 10, 10 conv layers). Depth loss: focal (gamma 2) with alpha_fg 3.25 inside 2D boxes and 0.25 outside; weights depth 3.0, cls 1.0, reg 2.0, dir 0.2; Adam 1e-3, one-cycle; KITTI voxel 0.16 m, x 2 to 46.8 m.

**Results that matter** [checked]: KITTI test Car AP|R40 easy / mod / hard 19.17 / 13.41 / 11.46 (first among published monocular methods); Waymo val vehicle L1 mAP 5.03. KITTI val Car moderate ablations: no depth supervision 5.66, with 14.03; LID 16.31 vs uniform 15.10 vs SID 15.65; full distribution 16.31 vs one-hot depth 13.71; joint training beats separate DORN (11.04) or BTS (10.18) depth; Block1 features 16.31 vs 14.7-14.9 from deeper blocks. Entropy of the distribution grows with depth. Runtime not on the page; OpenPCDet README lists about 15 h training for the KITTI baseline [checked on the repo page].

**Transferable technique** [the footprint reading below is the scout's inference, not a statement of the paper]: the voxel-centric trilinear lookup is itself a (small, fixed) footprint: it averages 2x2 neighbouring pixels and 2 depth bins per voxel centre. A cone lift generalises it by making the footprint size depend on range (the trilinear kernel has a fixed width in pixel space, i.e. a footprint that already grows linearly with range in metres, but the weights are not area-normalised in the BEV cell). LID spacing is the finding to keep for far range; the foreground-weighted focal depth loss is a ready recipe.

**Cost and fit**: the dense X x Y x Z x C volume is memory-heavy (GaussianLSS avoids it); fine on a 12 GB card only with small Z and C = 64; the OpenPCDet module (the frustum-to-voxel step, `pcdet` folder) is the reference to port from; the exact class name was not visible on the repo page.

**Doubts**: KITTI front camera, monocular 3D detection; a 16 h training run at 12 GB is not cheap; D is not stated on the page.
