Findings: positions are now a differentiable output of the chain (point-to-polyline loss, bilinear sampling at the current positions); one layer = three layers = detached; the planner loss reaches the positions but gains nothing (like E119); with the planner loss alone the refinement is undone. Still discrete: seeds, which vertices exist, topology, argmax steps, teacher-forced training.
Limits: train graphs in-sample for the trace network; single runs, joint runs one epoch; the loss does not penalise sliding along the lane; split / merge and route success not re-measured on the refined graph (edges not passed to the evaluator).
Process lessons: with five jobs on the 12 GB GPU the per-frame python loss loops of the joint arms ran 10 s / step (killed and rerun with one epoch alone: 0.7 s / step); SIGSTOP / SIGCONT on explicit pids pauses a lower-priority run; Git Bash has no python (use `wsl bash -c 'python3 file.py'` with patch files written by the Write tool); `tool sleep` is blocked, wait with a background until-loop.
