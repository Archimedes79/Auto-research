**What it does**: Topograph builds one component graph from the binarised prediction and the GT (nodes = connected components of TP, TN, FP, FN regions), marks nodes as critical if they are wrong and lack exactly one correct foreground and one correct background neighbour, and adds a loss = alpha x mean predicted-class score over the critical nodes' pixels; zero loss implies homotopy equivalence (proved), a random threshold shift (sigma 0.05-0.1) around 0.5 helps. Betti matching builds the induced matching between persistence barcodes of the prediction and GT filtrations (loss sum 2 ||q - mu(q)||^2 over matched pairs, combined with Dice, alpha 0.01-0.1) and needs a volumetric loss next to it.

**Results that matter** (Topograph, test, 5-fold, Dice / clDice / BM error): Roads (aerial) ours .817 / .711 / BM 5.64 vs Betti matching .818 / .707 / 5.91; Buildings .769 / .590 / 62.65 vs Dice-only .777 / .611 / 67.10; Cremi tied with clDice (BM 10.39 vs 10.37). Loss time per image (Table 2): Topograph 95.9 ms, clDice 9.9 ms, Mosin 233 ms, Betti matching 328 ms, HuTopo 603 ms; whole training 1h53 vs clDice 1h27 vs Betti matching 2h46. Efficient Betti matching 3D, DiceBetti vs Dice only: the Betti-matching error falls (VesSAP 3551 -> 2243, CREMI 44.8 -> 24.1) but clDice falls too (VesSAP 0.783 -> 0.723, CREMI 0.873 -> 0.808) and the Dice loss rises (VesSAP 0.286 -> 0.315): topology bought with volumetric overlap.

**Transferable technique**: none to port soon. The idea worth keeping is the evaluation side: a Betti-number / critical-component count of the predicted drivable area and centre-line mask as a metric next to IoU, to decide whether a connectivity term is worth testing.

**Cost and fit**: CPU, per-image Python / C loops, 2D only, binary thresholded prediction (the gradient reaches only the critical pixels), multi-class by repeating per class; the 96 ms average is per call on the paper's image size (not stated), so a batch of BEV maps would scale linearly with the batch. Soft labels and ignore masks are not covered.

**Doubts**: Betti matching trades overlap for topology (see above); Topograph's gains over clDice are mostly inside the paper's significance bands (Buildings DIU gap not all significant); no thin-line, dashed-line, or registration-noise setting.
