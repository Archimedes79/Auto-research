**The surrogate (written before any run).** Per TRAIN frame of the label dump: the valid tokens i with the head's p_none_i and the GT label g_i = ytype_i > 0 (the token loss's own type target: a token assigned to a GT node; its agreement with gt_id >= 0 is written to the fit json); the dump's candidate pairs (i, j) with p_ij >= 0.05 inside the gate, their class c (short / long = the head's token chord <= / > 8 m, as the decode), and y_ij = the token loss's own GT successor label (`labelled` batch `y`). Soft decisions: keep k_i = sigmoid((tau_keep - p_none_i) / T); link s_ij = sigmoid((p_ij - tau_c) / T) * k_i * k_j (the delivered decision: a link needs p >= the class threshold and both ends kept; the none gate stays off, as in the champion). Soft counts summed over all frames: TP_c = sum s y, FP_c = sum s (1 - y), FN_c = sum over EVERY GT link of class c of (1 - s), where a GT link with no candidate (p < 0.05 or outside the gate) has s = 0 (a full FN); softF1 = 2 TP / (2 TP + FP + FN); the keep term the same over the valid tokens with g. The class of a GT link outside the candidates: its token chord. T = 0.05 fixed. The thresholds of links are floored at 0.05 after the fit (the dump holds the candidates above it); a fitted tau_long below 0.15 is labelled (the dropped p < 0.05 candidates still carry soft mass near it). The fit reads TRAIN only; VAL is read once, at the rounded taus; no re-fit with another T, lr, init or step after any VAL number. **Scope (said, not fixed):** `y` holds the GT links whose two ends are both assigned tokens; a GT link with an unassigned end is invisible to the surrogate but an FN of the topo F1 (a lower F1 optimum, so the surrogate's best threshold may sit higher than the graph's); duplicate tokens beside a GT node are FPs of the keep term (the one-to-one 1.5 m assignment) while the scorer counts them only in dup_frac (the surrogate is stricter: tau_keep is pushed down); tau_keep gets gradient from all three terms through k_i k_j.
