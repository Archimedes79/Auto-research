**What it does** [checked]: maximise the worst-case improvement of any task inside a ball around the average gradient: max_d min_i <g_i, d> s.t. ||d - g_0|| <= c ||g_0||, g_0 = mean gradient. Solved in the dual over simplex weights w (K dimensions): minimise F(w) = g_w^T g_0 + sqrt(phi) ||g_w||, phi = c^2 ||g_0||^2, g_w = sum_i w_i g_i; the step is g_0 + sqrt(phi) g_w / ||g_w||. c in [0, 1): c = 0 is gradient descent, large c approaches MGDA; c = 0.4 on NYUv2 (0.2 or 0.4 on Cityscapes: the paper contradicts itself). Converges to a minimum of the average loss.

**Results that matter** [checked; MTAN backbone, Delta_m % lower is better]: NYUv2 (3 tasks): MTAN (equal weights) 5.59, MGDA 1.38, PCGrad 3.97, GradDrop 3.58, CAGrad 0.20; Cityscapes (2 tasks): MTAN 22.60, PCGrad 18.29, GradDrop 23.73, CAGrad 11.64. Later tables (FAMO, LDC-MTL) list Nash-MTL -4.04, FAMO -4.10 on the same NYUv2 rows, so CAGrad is a mid-field method today. RL training time per update: MT10 PCGrad 9.7 s, CAGrad 10.3 s, CAGrad-Fast 4.8 s; MT50 59.8 / 27.8 / 11.4 s.

**Transferable technique**: only the structure (a K-dimensional dual problem on the Gram matrix of the task gradients; subsampling tasks for speed, "CAGrad-Fast"). With K = 4 the Gram matrix is 4 x 4 and the solve is trivial; the cost is the four gradients.

**Cost and fit** [checked]: K backward passes for the individual gradients (the paper: "a method usually requires K back-propagations"), time O(|S| N + T) with S the sampled task subset; the repo notes that dropping `retain_graph=True` on the last backward saves much GPU memory. Taken at the parameters of a BEV trunk this is 4 trunk backward passes per step; taken at the shared BEV feature tensor (gradient w.r.t. the feature, then one trunk backward with the combined direction) it costs 4 head backward passes plus one trunk pass.

**Doubts**: equal-weight MTAN baseline (5.59) is weak next to tuned scalarisation (2201.04122, 2209.11379, 2408.07985); the hyperparameter c is task-specific; no detection / BEV task; not compared in 2201.04122.
