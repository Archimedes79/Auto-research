## 1. Problem and claim
Probabilistic object detectors give a box distribution per detection, but existing scores (PDQ, calibration error with thresholds, mAP) need confidence thresholds or restrict the distribution family. The paper views the detector output as a distribution over sets of objects (random finite set, RFS) and scores it with the set negative log-likelihood, a local proper scoring rule. The output model is a Poisson multi-Bernoulli (PMB): one Bernoulli (existence r, density over class and box) per detection, plus a Poisson point process (PPP) that explains ground-truth objects no detection claims. The claim that matters: PMB-NLL is a threshold-free score that also trains (the MB part, with Q = 1 assignment, PPP dropped), and fine-tuning with it lowers PMB-NLL for all three tested detectors (DETR, RetinaNet, Faster-RCNN) on COCO, while mAP is kept for two of them and drops for Faster-RCNN. Nothing in the paper concerns lanes, thin structures, point objects or matching-free training.

## 2. Method as built

### 2.1 Pipeline
```
 image -> (existing detector, unchanged architecture)  -> m predictions, each:
              class distribution p_cls (incl. background / existence r),  box density p_reg (per-coordinate Laplace,
              scale from the predicted Cholesky diagonal),  (up to 100 per image, no confidence threshold at eval)
 ground truth  Y = {y_1..y_n}, y = (class c, box b in R^4, corners x1 y1 x2 y2)
 evaluation:   PMB-NLL(Y)  via Eq. 13 with Q = 25 best assignments (Murty)           -> one number per image
 training:     MB-NLL loss: Q = 1 assignment, PPP ignored, L2 in the matching cost  -> fine-tune pretrained models
```
No new network head: the paper takes pretrained probabilistic detectors (probdet / Detectron2 family) and only changes the loss and the score.

### 2.2 Inputs, outputs
- Output of the detector as a set model: m Bernoullis (r_i, p_i), i = 1..m, plus a PPP intensity built from the same output (below). Ground truth: n objects. All densities are over the object state y = (c, b) in box coordinates (pixels), so the absolute NLL values depend on the coordinate unit (my inference: only differences between models on the same unit are meaningful).
- Boxes are given by two corners; the regression density is an independent Laplace per coordinate (Appendix 0.B.1 / Eq. 30), taking the diagonal of the predicted covariance (the models predict a Cholesky factor L with Sigma = L L^T; off-diagonals are not used).

### 2.3 Equations (numbering as in the digest of the paper)
- E1: `NLL = -log f(Y | X)`, f a density over finite sets.
- E2 Bernoulli: `f_B(Y) = 1 - r` for the empty set, `r p(y)` for a single object, 0 for more. `p(y) = p_cls(c) p_reg(b)` (classification and regression assumed independent).
- E3 multi-Bernoulli: `f_MB(X) = sum over all ways to split X into m disjoint (possibly empty) parts X_1..X_m of prod_j f_Bj(X_j)`. Consequence: if there are fewer components than objects, f_MB = 0, NLL infinite.
- E9 PPP: `f_PPP(X) = exp(-lam_bar) prod_{x in X} lam(x)`, `lam_bar = integral of lam`. Cardinality is Poisson, so every set size has non-zero probability.
- E10 PMB: `f_PMB(X) = sum over splits X = X^U + X^D of f_PPP(X^U) f_MB(X^D)`: each object is either undetected (PPP) or detected (assigned to one Bernoulli).
- E11 intensity: `lam(x) = sum_i r_i p_i(x)` over the low-confidence predictions only. Predictions with r < 0.1 are removed from the MB and are used for the PPP only (heuristic threshold, motivated by a KL argument from the multi-target tracking literature). The paper also tried a uniform intensity and a constant mixture and kept this one (no numbers).
- **Global association hypothesis** (Appendix 0.A): an association theta maps each ground-truth object to one Bernoulli or to the PPP (theta = 0); encoded as an (m+n) x n 0/1 matrix A with column sums 1 (every object explained once) and row sums at most 1 (a Bernoulli explains at most one object). The full likelihood is the sum over all such A (exponentially many).
- E12 cost matrix (rows m + n, columns n): entry (k, l) is `-log( r_k p_k(y_l) / (1 - r_k) )` for a Bernoulli row k <= m, `-log lam(y_l)` on the diagonal of the PPP block (row m + l), infinity elsewhere. There is no separate empty column: the factor (1 - r_k) of an unassigned Bernoulli is pulled out of the product, so each Bernoulli enters as a ratio r/(1-r) (my reading of the derivation).
- E7 / E21: the most likely hypothesis minimises `sum C_kl A_kl`: a linear assignment problem; the Q best assignments come from Murty's algorithm.
- **E13 (how the sum is approximated):** `NLL ~= integral(lam) - log( sum_{q=1..Q} prod_{y in Y^U(A_q)} lam(y) * prod_{k=1..m} f_Bk(Y_k(A_q)) )`. The sum over all hypotheses is truncated to the Q best; Q = 25 at evaluation ("larger Q changes nothing", no curve shown). Truncation keeps the likelihood a lower bound on the exact one (my inference: dropping non-negative terms).
- E14 (Q = 1 decomposition): NLL = classification `-sum log(r_i p_cls,i(c_j))` over matched pairs + regression `-sum log p_reg,i(b_j)` over matched pairs + false detections `-sum_{i unmatched} log(1 - r_i)` + missed objects `integral(lam) - sum_{j missed} log lam(y_j)`.
- E30 regression NLL per box (4 coordinates): `sum_k |b_k - b_hat_k| / s_k + log s_k + log 2`, with Laplace scale `s_k = sigma_k / sqrt 2`. The paper says Laplace gave considerably lower NLL than the Gaussian of the pretrained models (no numbers).

### 2.4 Losses (what trains)
- **MB-NLL (E32, written in DETR notation):** per query i, `-log p_cls,sigma(i)(c_i) + [c_i is an object] * sum_k ( |b_ik - b_hat_ik| / s_k + log s_k )` with sigma the Q = 1 assignment. Predictions assigned to "no object" pay `-log(1 - r)`; unlike the DETR loss this background term is **not** down-weighted.
- **Assignment rule in training: yes, a hard one-to-one assignment.** It is the assignment problem of E7 with Q = 1; spatial uncertainty is dropped from the matching cost (L2 distance instead of the regression log-density, said to be more stable); the PPP is ignored in training ("the aim is to detect all objects"); Q = 1 chosen because training was more stable than with more assignments. The digest does not state the solver for the Q = 1 case (Hungarian is named only for DETR's own loss, Appendix 0.D.1; the repository ships the fastmurty package for the assignment). The paper calls the loss differentiable; the discrete assignment is a constant for the gradient, so gradients flow only through the selected pair terms (my inference; not spelled out).
- **No marginalisation over assignments and no soft assignment in training**: the likelihood sum of E13 is used at evaluation only.
- Cost over a standard loss: no timing for Murty, training or evaluation is reported (Section 3.2 only calls the Q best assignments efficient). Extra work per image is one (m + n) x n assignment problem solved by an external compiled library (fastmurty) in training, 25 assignments in evaluation (my reading; no measurement exists in the paper).

### 2.5 Labels / ground truth
COCO boxes. Nothing beyond that is needed; no extra target construction.

### 2.6 Training recipe (Appendix 0.B.2, digest)
- Start from pretrained probabilistic Detectron2 models: DETR and Faster-RCNN from energy-score (ES) trained weights, RetinaNet from NLL-trained weights; fine-tune with MB-NLL.
- RetinaNet and Faster-RCNN: 135,000 steps, lr 0.001 (RetinaNet) / 0.0025 (Faster-RCNN), divided by 10 at 105k and 125k. DETR: 135,000 iterations, lr 5e-5, divided by 10 at 60k and 100k. Other settings from Detectron2; the authors note that a smaller batch size (hardware limits) lowered mAP against Detectron2 reference numbers. Batch size, GPU and wall-clock time: not found in the digest.
- NMS (IoU 0.5, top 100) is applied for RetinaNet and Faster-RCNN also while training with MB-NLL; DETR needs none.

### 2.7 Inference
Up to 100 predictions per image, no confidence threshold, no NMS for DETR (NMS IoU 0.5 for the other two). PMB-NLL then uses Q = 25 assignments and the PPP from predictions with r < 0.1.

### 5.1 What is the "object" and where does the intensity come from (my design, not in the paper)
- **Object:** one ground-truth vertex x_j in the BEV plane (position on the 0.5 m grid; direction as an optional second mark). Hypothesis i: validity r_i (the existing per-vertex existence), mean mu_i, covariance Sigma_i (2 x 2; see the point-object issue below), giving a normalised Gaussian density p_i(x) = N(x; mu_i, Sigma_i).
- **Intensity:** the paper builds lam from low-confidence predictions only (r < 0.1) because the MB part explains the confident ones. With the matching-free design below there is no MB / PPP split: take lam over **all** hypotheses, `lam(x) = sum_i r_i p_i(x)`. The "intensity of undetected vertices" is then the low-validity tail of the same sum, and it rises where the head is unsure but not empty (far range). Where no hypothesis exists at all (nothing proposed beyond 40 m) lam = 0 and the loss is infinite; this is the paper's own reason for adding a PPP. Fix by adding a small background intensity floor, e.g. a learned smooth field from the dense lane head (A2) sampled at x, or an eps-floor (my design; the paper tried a uniform intensity and a constant mixture and reports no numbers).
- **Matching-free training loss (my design, PPP-only / PHD view):** `L_phd = integral(lam) - sum_j log( lam(x_j) + eps )`, with `integral(lam) = sum_i r_i` when each p_i integrates to 1 inside the BEV window (the paper does not state this identity; mine, true for normalised densities away from the window edge). The log of a sum over hypotheses is a soft marginalisation over the assignments (a mixture), so no Hungarian, no argmax and no rule step; gradients reach r_i, mu_i and Sigma_i. Cost O(m n) with a sparse top-k neighbourhood (n up to a few hundred per frame, m the builder's hypothesis count, both unmeasured here).
- **What this loses against PMB:** the Bernoulli constraint (a hypothesis explains at most one vertex, r_i <= 1 is a probability of one object) is not enforced, so duplicates are not penalised by the likelihood itself and several low-validity hypotheses can share one vertex; the loss fixes `sum_i r_i` to the number of GT vertices (a cardinality calibration in the Poisson sense), not each r_i. Existing duplicate repulsion (`dup_geo` / `dup_learned` in the loss file) must stay.
- **Variant with Bernoulli flavour, still matching-free (my design, untested):** noisy-OR occupancy on the 0.5 m grid, `rho(c) = 1 - prod_i (1 - r_i k_i(c))` with k_i a peak-1 kernel of hypothesis i, trained with BCE against the GT occupancy of cell c. This is a per-cell Bernoulli field (the lattice multi-Bernoulli), exact in its own model, no association needed because the component is the cell. It is a close relative of what the dense lane head already does; the new part is that it trains the **hypotheses'** r_i and Sigma_i through the splat.

### 5.2 Point objects and thin structures (the question about objects without extent)
- The paper treats only boxes; a point-object or zero-extent case is not discussed. Its intensity is a mixture of box densities and the integral term is not worked out in closed form (digest).
- For us the vertices are points on a one-dimensional curve. Three consequences (my reasoning): (1) the GT set of a 0.5 m grid is an arbitrary sampling of the centre line, so a Poisson model with independent points has the wrong dependence; the along-track density should be flat, the cross-track density narrow. An isotropic Sigma either blurs the cross-track direction or forces the along-track error to be tiny. Use two scales aligned with the predicted direction (small cross, larger along), or a loss only in the cross-track coordinate plus a separate along-track coverage term. (2) The log-likelihood has no scale: changing the grid spacing from 0.5 m to 1 m changes the sum by a constant per vertex, so numbers are only comparable at the same grid. (3) A hypothesis between two grid vertices is penalised by the nearer-vertex mixture only through its Gaussian tails; this is acceptable at a cross-track scale of 0.3 to 0.6 m (the champion's verification uses 0.6 m, as in the loss file) but untested.
- Covariance outputs: the paper uses only the diagonal of a Cholesky factor and a Laplace density; Gaussian with a full 2 x 2 matrix is a straightforward replacement for points (my design). Gaussian NLL needs bounds on the log scale to avoid collapse (a floor on the cross-track scale, e.g. at the label noise) - not in the paper.

### 5.3 Design sketch, prediction and decision rule (proposal; the card with the final numbers is written before any run)
- **Where:** a new term in `training/losses/p16_loss.py` next to `graph_losses` (reads the builder's node positions and validity); covariance as an extra small head in `training/models/p16_builder.py`; calibration evaluation as an extension of `evaluation/` (reliability of validity by range bin, with a bootstrap), never a private metric script.
- **Arms (equal budget, 2 seeds):** control = champion recipe; A = control + `w * L_phd` with fixed isotropic Sigma (cross 0.5 m); B = A with learned anisotropic Sigma and a scale floor; C (optional) = noisy-OR occupancy BCE. Null: L_phd with GT shuffled across frames; sanity: oracle hypotheses at GT positions must give the lowest loss.
- **Layer 0 spec test (toy with a known answer):** one GT vertex, one hypothesis with r = 1 at the vertex and Sigma = s^2 I in 2D: `L_phd = 1 + log(2 pi s^2)` (a Gaussian density at its own mean, integral 1). With r hypotheses duplicated k times at the same place, `sum_i r_i = k r`; the loss is minimised at k r = 1. Reproduce the Q = 1 cost matrix of E12 on a 3 x 2 toy by hand and check that the PPP-only loss equals the Poisson form.
- **Prediction (my guess, numbers to be fixed on the card):** Q within +-0.010 of the control; R@1 far +0.01 to +0.03; lanes found at range up by up to 0.02; reliability error of validity (expected calibration error with 10 bins, per range) lower by a third or more; ms per frame unchanged (the loss is training-only).
- **Decision rule (skeleton, in the style of `decide.py`):** KEEP if the R@1 far gain over the control exceeds the noise band 0.010 with the paired scene bootstrap excluding 0 on both seeds, Q does not fall by more than 0.010, topo F1 does not fall, and the validity calibration error improves; TIE otherwise (take the control, the cheaper variant); INCONCLUSIVE means one more seed. Calibration alone improving with no coverage gain is a result for A8, not a promotion.
- **Cheapest first step with no training (layer 1):** compute L_phd and the decomposition (false-positive mass: sum of r_i of hypotheses far from any GT; missed vertices: -log lam at GT; per range bin) on the stored `champion`, `recall` and `control` outputs on VAL, which shows whether the gap at range appears as missed-vertex cost before any loss is trained. Effort S.

### 5.4 What does not transfer
- Box density (Laplace on corners), class probabilities, COCO, Detectron2/DETR/Faster-RCNN/RetinaNet, NMS, pretrained probdet models, PDQ and the mAP comparison.
- The Q = 1 hard assignment used for training, and fastmurty (a compiled library on the training path): excluded by the no-matching rule. The Q = 25 evaluation score could be used only as an offline VAL diagnostic, not on the training path (the evaluation rules of the project were not checked for matching-based metrics).
- The PPP threshold r < 0.1 as a rule step is a rule step; if used as a soft weight (for instance a sigmoid of r) it is differentiable but unproven.

## 8. Novelty and relevance for our problem
The novelty is the RFS view of a detector output: a Poisson multi-Bernoulli whose Bernoulli part carries per-detection existence and whose Poisson part explains missed objects, scored by the exact set NLL, used both as an evaluation measure and as a (Q = 1, PPP-free) fine-tuning loss. For us the value is the likelihood structure, not the recipe: a set of vertices with existence probabilities, positions and covariances maps onto it directly, and the PPP intensity gives "undetected vertices at range" a mathematical home. The trained loss in the paper still uses a hard assignment, which our rule excludes, and the PPP never enters training, so the part we want (coverage) is the part the paper did not train; a matching-free variant (mixture / PHD likelihood, or noisy-OR occupancy) is my construction and has no evidence behind it. Evidence is one COCO protocol with box objects and single runs; nothing about calibration or thin structures.
