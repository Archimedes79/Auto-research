Process lessons: `pkill -f "[_]run_x.sh"` on a wrapper can kill its python child (the hold-out run had to be restarted); a wrapper `.done` flag does not prove the run completed; Start-Process wsl with a wrapper script file is the working way to start background jobs (a `&` inside `wsl bash -c` dies with the call); three or four jobs on the 12 GB GPU slow every job 3 - 4 times (consumer runs 70 s alone, 4 - 5 min together); a patch file written by bash heredoc with `\n` inside a Python string produces real newlines (use the Write tool for patch files); a learned input that is unnormalised (the 128-d step token) can make a consumer worse and unstable.
