# training - code of the camera + radar BEV system

Plain PyTorch (env `gcar`: PyTorch 2.8, Python 3.12, no mmcv). Every module has a self-test with known answers (`python training/<module>.py`).

| file | what it does | self-test |
|---|---|---|
| `camera_encoder.py` | front-camera encoder with pre-trained camera heads: ResNet-50 + CustomFPN + DepthNet (camera-aware gate, 27-vector) with DualBEV's layer names (`load_pretrained` reports missing / unexpected / shape-mismatched keys), depth softmax over 118 bins (1-60 m) -> lift PD -> BEV (B, 128, 120, 104); `freeze_camera_heads` keeps backbone, neck, DepthNet frozen with BatchNorm in eval mode; `nuscenes_front_ida`, `camera_vector` | shapes, key names, image transform, one camera alone = in a batch, frozen heads get no gradient |
| `radar_bev.py` | radar block (simple): detections from any rig (position, distance, ray direction in the vehicle frame, Doppler, RCS, age) -> hard raster into the cell they reside in (count, mean properties with direction and Doppler as circular values, sub-cell offset) -> two 3x3 convs -> (B, 32, 120, 104) on the camera BEV grid; `to_vehicle` (sensor polar + pose -> vehicle frame), `doppler_code`; information-preserving variant `rasterize_slots` / `decode_slots` / `RadarBEVSlots`: K = 3 detections per cell stored exactly + remainder mean + count, exact inverse | periodic Doppler code, sensor pose, cell and properties, mean of a cell, frames, rig independence, module; slots: exact round trip of eight fields, several detections per cell, overflow + remainder, module |
| `radar_encoder.py` | radar block that keeps the information (plan.md 3.4): delta-coded slot raster (K = 3 exact slots + remainder mean + count; per slot valid, dr = r - \|c - s\|, dpsi = psi - bearing(c - s), Doppler code, rcs, age, sub-cell offset, ray origin s; position = cell index + offset, r and psi decoded exactly from cell + origin + residual) -> two 3 x 3 convs, LeakyReLU, C >= inputs, pass-through start; `aux_loss` = tolerance-weighted reconstruction as a SIDE loss with `aux_weight(step)` decaying to a floor (the task losses are the goal), `kept_fraction` = measurement of what the features still hold (no gradient), `forward(..., with_state=True)` = the lossless raster as explicit stream; `rasterize_delta_slots` / `unpack` / `decode_slots`, `new_decoder` for probing frozen features | exact round trip of eight fields (two frames, several sensor poses), residual bound, overflow + remainder mean, Doppler wrap, supplied ray origin, module shapes, side-loss gradients, pass-through start has the lower side loss than a default start |
| `splat.py` | temporal block: move BEV cells or radar detections to another time - velocity head f_theta (1 x 1-conv MLP, 2 outputs, zero start), positions p' = R(-omega dt)(p + v_hat dt - d) with ego speed / yaw rate (translation first order in omega, rotation exact), normalised bilinear softmax splat with a mass channel; `CorrectionHead` (learned bounded position correction from feature + ego motion, zero start); `ego_speed_yawrate` (v, omega from poses); `splat_bev` for maps, `splat` for points; synthetic scene checks in `../temp/checks/` | exact 2-cell shift, landing point vs formula and exact turn, object velocity, forward-back, mass conservation, collision, gradcheck, head learns, moving blob, v / omega from poses, correction zero start / bound / gradient |
| `temporal_fusion.py` | per-branch temporal fusion, ONE class for camera and radar: current planes + the last K original frames brought in by `splat_window` (aggregated with mass x exp(-age / tau) x a learned relevance; summed mass and mean age as channels) + a static memory in a WORLD-ALIGNED grid (written once and read once per frame, never resampled, so nothing blurs or lags; lossless re-centring by whole cells; moving content kept out through a velocity-derived static weight) -> conv3x3. Explicit data (radar Doppler vectors / tensors, counts) via `n_explicit`, `vec2`, `sym2`: rotated with the ego rotation, kept out of the memory | lossless re-centring, fresh source dominates, memory vs world pattern straight (corr 1.00 -> 0.97) and turning (>= 0.95), no ghost trail of a moving object (0.002 vs 0.157 without velocity), window sources vs current frame, gradients to head / relevance / tau / fusion, explicit vector and tensor rotation, empty inputs; 3.0 GFLOPs, 115 k parameters at 64 channels, 120 x 104, K = 3 |
| `fusion.py` | camera-radar fusion at camera time, plug-in modules in front of the trunk: `ConcatFusion` (concat + 3x3 conv, the plan's main), `GateFusion` (per-channel and per-cell cross-gates in the spirit of GaussianCaR's FeatureRectify, re-implemented; `gates()` for plotting), `drop_modality` (modality dropout: one of the two modalities zeroed per sample, never both). Binary-data experiment: `temp/checks/check_fusion_binary.py` | shapes, gradients, modality dropout statistics, no dropout in eval, camera stream unchanged with the radar off, gates in [0, 1] |
| `timed_head.py` | time decoding inside every head: `MotionHead` (explicit velocity field + `loss`), shared `TimeMover` (velocity + ego motion + splat with a mass channel), `TimedHead` wrapper per head (refine block with FiLM by dt, zero start; dt = 0 is the plain head) | dt = 0 = plain head, ego motion at x -+ v dt, unknown share v dt / 60 m, object velocity, motion loss, one mover shared by the semantic and object head, gradients |
| `bev_trunk.py` | BEV trunk after the fusion, the standard flow of BEVDet / BEVDepth / CRN / DualBEV in plain PyTorch with a width factor: 3-stage ResNet pyramid (strides 2 / 4 / 8) + FPN_LSS decoder + semantic head; option `detail=32`: stride-1 detail path (two 3x3 convs at 0.5 m on the input, concatenated before the head); DualBEV layer names (`load_pretrained` loads its BEV encoder: 98 tensors, 0 missing); `light_up` = sub-pixel up-sampling instead of the full-resolution 3x3 conv. FLOPs per candidate: `temp/checks/trunk_flops.py` | shapes of the three stages and the output, parameters + BatchNorm statistics = DualBEV's 26,668,896 tensors, light variants, gradients |
| `gt_bev.py` | compatibility shim (since 2026-10-30): the GT generator lives in the standalone suite `../autogt/` (static layers, objects, masks, radar-corrected velocity / flow in m/s, training samples, build / check / view / video commands); this file re-exports NuScenesGT, Raster, AREAS / LINES / OBJECTS, cell_centres, occlusion, pose_matrix, category_group | `python -m autogt selftest` (from the bev_fusion folder) |
| `train.py` | trainer for the whole chain: the model's head layout from the `LossConfig`, targets from `sample_targets` (GT at -0.5 / 0 / +0.5 s = past AND future), AdamW (decay only on weights of dim >= 2) with warm-up from lr / 3 + cosine, gradient accumulation (effective batch = `batch_size` x `accum`), grad clipping, EMA, optional bf16, non-finite guard (skips the whole step), task-balancing arms `balancing` = kendall / fixed / uwso, optional train-only cross-time consistency (`consistency`, own warm-up), optional gradient-conflict log (`grad_diag_every`), sequence training (`seq_len`, `seq_bptt`: clips of consecutive keyframes of one scene, the world memory carried with the ego step between them, detached or kept in the graph; validation reports the last keyframe warm and cold), atomic checkpoints with resume (the frozen camera heads are not stored), JSONL log, validation under the EMA weights, `eval_fn` hook for evaluation/metrics.py; config = `TrainConfig` JSON | GT at three times -> finite loss, balancing arms, consistency (hold = weight 0, gradient reaches the motion head), gradient cosines, clips (consecutive keyframes, the carried memory changes the prediction, an attached state reaches the earlier keyframe), accumulation, 4 steps with checkpoints, resume 4 -> 6, validation restores the weights, schedule |
| `loss_extras.py` | loss pieces beyond `losses.py` (state of the art 2026-10-26, each with its paper): `dice_semimetric_loss` (2303.16296: exact on soft targets, 0 at p = t), `boundary_fp_loss` + `ramp` (1812.07032 with the stored distance field), `UWSO` (2408.07985, drop-in for `losses.TaskWeights`), `group_gradient_cosines` (conflict diagnostic before any gradient surgery), `beta_nll` (2203.09168, needs a log-variance channel), `cross_time_consistency` (bidirectional, UnFlow-style forward-backward occlusion check, ego-exact chain, visibility weights, stop-gradient per direction) | each loss against its closed form, UW-SO weights, cosines of known directions, beta-NLL limits, consistency: moving blob 0.014 vs no motion 0.032, pushed-out field 0.50 not 0, ego motion exact, gradient per direction |
| `feature_cache.py` | cache of the frozen camera heads' outputs (derived data in `data/cache`, resumable build per scene, float16), `CachedFrontRadarDataset` (no image is read), `collate_cached`, `CachedBEVFusionModel` (camera branch reads the cached outputs; the 54.6 M frozen parameters are not instantiated) | build + resume, probabilities sum to 1, no images read, camera BEVs = the standard model's within 2.6e-4 of their range, whole-chain outputs equal |
| `gt_cache_build.py` | prefills the GT cache (`data/cache/gt`) with several worker processes before training, through the dataset's own cache writer (cold GT costs seconds per sample, 12 s on the trainval maps, and would stall the trainer); resumable; the key contains the signature of `gt_bev.py`, so an edit of the GT generator means a new prefill; CLI: `python training/gt_cache_build.py <dataroot> <version> <cache_dir> --split train --workers 4` | 4 mini samples cached by 2 workers, the second pass reads them without generating |
| `fallbacks.py` | paper fallbacks with the interfaces of the blocks they replace (re-implemented, no copied code): `EgoWarpGRU` (FIERY-style exact ego pull of the state + ConvGRU, interface of `TemporalFusion`; temporal control arm A), `LiftS` (LSS / BEVPoolV2 forward splat, cached index table, interface of `LiftPD`), `CMXFuser` / `CMXDecoder` / `CMXTrunk` (GaussianCaR's four-stage camera-radar fusion pyramid with rectify + efficient cross-attention, replaces fusion + trunk; 36.4 GFLOPs, 9.3 M parameters) | exact 2-cell ego shift + invalid rows, rotation = inverse of `splat_positions`, GRU gradients; S table vs analytic ray, one-hot depth inside PD's support, mass conservation, rig shift, gradcheck; CMX scale shapes, gradients, camera stream unchanged with zero radar |
| `losses.py` | the losses of plan 8.4: `layer_spec` (the semantic head's 12 channels: 5 areas, 2 line masks, 2 distance fields, 3 dense objects; + centre-lines), `build_layer_targets` (per-cell weights: undefined 0, occluded 0.5 (decision 1), unknown at the target time 0.5, unobserved boxes (no lidar / radar point) ignored in every object target), areas BCE + 0.5 (1 - soft IoU) (arm: Dice semimetric), lines dilated Dice + Huber on the distance field (arm: ramped boundary loss), dense objects (decision 2: kept), object head stage 1 via `object_head.head_loss` (unobserved boxes neither positive nor negative), motion via `MotionHead.loss`, aux heads, w(dt) 1 / 0.5 / 0.25 with warm-up, Kendall task weights over areas / lines / objects / motion (s in [-3, 1]); `BEVLoss(preds, sample_targets(gt), step_frac)` takes `model.py`'s output as it is; the open decisions are `LossConfig` switches | soft BCE analytic, tolerant Dice 0 at 1 cell / 1 at 3, exact field -> Huber 0, weight-0 cells get zero gradient, doubled map leaves every term unchanged, Kendall clamp, dt weights + warm-up, unobserved box ignored, arms, overfit 100 steps 44.9 -> 1.4 |
| `nuscenes_dataset.py` | `FrontRadarDataset`: one item per keyframe = front camera now + older 12 Hz frames (704 x 256, K, T_cam_car, 27-vector, ego steps per frame), radar detections of all 5 radars of the last 0.5 s at the camera time (exact poses, radial Doppler shift), GT of k-1 / k / k+1 (gt_bev, optional float16 cache); `collate` (padded steps + `steps_raw` per sample), `available_scenes` | 384 mini samples, frame ages and ego steps, 5 radars, age <= 0.5 s, pose transform = chained steps within 0.022 m, GT, collation |
| `model.py` | the whole chain, every block swappable in `ModelConfig`: lift `pd` / `p` / `s` (LSS, fallback), camera temporal `window_memory` / `ego_gru` (FIERY, fallback) / `none`, radar temporal, fusion `concat` / `gate` / `cmx` (GaussianCaR, fallback), BEV trunk, shared `TimeMover` + `TimedHead` semantic and object heads at any dt, auxiliary per-branch heads; `refine=True`: S5c box refinement trained in the chain (candidates from decoded + jittered GT boxes, unobserved / unsupervised boxes ignored, `refine_loss` in the objects group) and `boxes(res, dt)` for refined boxes at run time; sequence mode with returned state | two mini samples through the chain at dt 0 and +0.5 s, frozen camera heads get no gradient, gradients reach reduce / radar / trunk / mover, state round trip, every swapped block runs, S5c training path (gradient to the refiner, trainer float cast) |
| `light_encoder.py` | light image encoder with stride-8 features (plan 2.7, a try approved 2026-10-30): ImageNet-initialised ResNet-18 / EfficientNet-B0 / B2 (torchvision weights in `models/pretrained/imagenet/`) + FPN (128 ch) + camera-aware SE gates + depth head (118 bins, the teacher's) and context head (80 ch); the same call as the frozen DualBEV heads (`image_features(img, cam_vec) -> prob, ctx`), 32 x 88 cells (stride 16 option); `distill_loss` (KL to the teacher's depth distribution + relative context MSE after 2 x 2 pooling) | shapes, softmax, camera vector changes the depth, gradients, ImageNet weights loaded, distillation loss zero for the pooled teacher, pooling alignment |
| `distill_light_encoder.py` | distils the frozen DualBEV heads (cached outputs of `feature_cache.py`) into the light encoder: images as the teacher saw them, 2 loader threads, bf16, resumable; eval KL / context error / expected-depth error to the teacher by range; run through `temp/timing/run_e8_queue.sh` after the training rounds; `--smoke` on nuScenes mini (CPU) | smoke run ok (20 steps) |
| `lift_pd.py` | camera block: lookup table per calibration (voxel -> image position + fractional depth bin) and lift PD (pull with depth weight: feature x p(depth) by two grid_sample gathers), height into channels; option learned elevations; `use_depth=False` = lift P | geometry, uniform depth = P / D, one-hot depth, rig shift (camera 1 m forward = BEV shifted 2 cells), gradcheck incl. learned heights, module |

`configs/` holds the training configurations (`python training/train.py configs/<name>.json`, base `t1_base.json`, arms in its README); the cache of the frozen camera heads is built by `../temp/setup/build_full_cache.sh` (data/README.md).
