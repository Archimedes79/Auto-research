**What it does** [checked]: auxiliary training loss for online map builders that otherwise train only against per-frame GT. (1) BVCL, vector level: past instances with confidence above tau = 0.3 are warped into the current frame with the ego motion, the current predictions into each past frame with the inverse motion; matching is Hungarian (class cost + SmoothL1) then point-level; forward and backward terms each have a point SmoothL1 and a class-distribution KL; past frames weighted by w = [9, 7, 5, 3, 1] (position) and u = [1, 0.7, 0.5, 0.3, 0.1] (semantics), nearer frames count more. (2) RCL, raster level: a BEV segmentation head gives a binary raster map (focal loss to the rasterised GT); a second focal loss compares the current raster with the warped past rasters, weighted per frame; L_RCL = 1.0 x L_seg + L_ras. Total L = L_map + L_BVCL + L_RCL. No overlap or occlusion mask; whether gradients flow into both frames is not stated.

**Results that matter** [checked, nuScenes new split, StreamMapNet base, mAP]: baseline 35.2; forward-only vector consistency 35.9, bidirectional 37.2 (the bidirectional gain over forward-only is 1.3); raster consistency part 38.2; full 38.9 (+3.7 mAP, +2.8 C-mAP). Other bases: SQD-MapNet +1.3, MapTracker +1.6 mAP. Argoverse2 memory size N_t: 1 / 3 / 5 / 7 frames give 55.9 / 56.0 / 56.7 / 51.6 mAP (7 frames HURT); tau 0.1 / 0.3 / 0.5: C-mAP 23.8 / 37.9 / 36.5. Inference FPS unchanged. Training 4 x A6000, batch 16; no training-time overhead reported.

**Transferable technique**: for dense BEV outputs the raster term is what we need: for each pair (current frame, past frame within 0.5 s) warp the past PREDICTION into the current time with the same splat (ego motion + velocity) and penalise the difference to the current prediction, and the reverse (current warped back, compared to the past prediction): a cycle between dt = +0.5 and dt = -0.5 without extra labels. Per-frame weights falling with age. What to ADD to their version: the splat mass (0 = unknown) and the GT visibility masks, so unknown/occluded cells do not produce a consistency loss; stop gradient on one side (OnlineBEV in the table uses stop-grad on the current branch with weight 2: +0.4 mAP / +0.5 NDS).

**Cost and fit**: one extra warp + loss per pair, no inference cost; the past predictions come from the same sequence pass (already computed with the recurrent memory). Memory: one more activation map per past frame kept in the graph (unless detached).

**Doubts**: gains are on vector-map mAP with a streaming base, whose temporal handling is weak; no code; no mask means the loss also punishes correct changes (a car that really moved); 7-frame window worse than 5: more history is not monotone; single runs.
