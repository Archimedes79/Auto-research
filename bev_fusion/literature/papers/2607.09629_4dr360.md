**What it does**: For each of the last T_h frames a cache keeps state features, occupancy logits, the ego pose and a BEV motion field built from box velocity and radar Doppler. Ego alignment moves cached features into the current frame. Moving content: the detection features decode a velocity map; occupancy confidence selects dynamic foreground, radar Doppler corrects the motion cue, and the displacement is clipped by tau (Eq. 9). Each cached state is bilinearly sampled from the source location that moves into each current cell (shared across height bins). Warped memories are averaged with temporal decay lambda^k and confidence weights; the current state is refined residually, V~_t = V_t + Conv3D(M_t). The paper says ego compensation alone "cannot handle moving objects"; there is no separate static-only path (static = zero displacement).

**Results that matter** (ManTruckScenes, 4 frames, Table 8): no temporal 47.45 mAP / 50.89 NDS / 30.22 mIoU / mAVE 1.0213; ego align only 47.12 / 50.45 / 29.96 / 0.9986 (ego warp alone is below no history); state memory 49.06 / 52.28 / 30.92 / 0.9824; DTF with Doppler 49.57 / 52.97 / 31.65 / 0.9442. Horizon: BEV-TF with 2 frames is below single-frame; DTF with 2 frames 48.62 / 52.05, with 4 frames 49.57 / 52.97. Speed: whole model 4.5 FPS (OmniHD-Scenes) and 5.5 FPS (ManTruckScenes); no DTF-specific latency or memory (deferred to the supplement).

**Transferable technique**: displacement = clipped velocity x dt applied as a dynamic warp, with occupancy-confidence weights; confidence-weighted decay average of warped memories as the fusion rule (a mask-aware EMA). The ablation order (state memory first, Doppler warp adds +0.5 mAP / +0.7 NDS on top) shows the warp is a second-order gain.

**Cost and fit**: Whole model is slow (4.5 - 5.5 FPS), the cache holds T_h full states, so far from small-GPU real-time; the idea, not the code, ports.

**Doubts**: Truck (ManTruckScenes) and OmniHD-Scenes data with 4D radar, not nuScenes; Doppler contribution is +0.5 mAP; no latency isolation; unreviewed preprint.
