# 2404.03010 Skeleton Recall Loss - connectivity loss for thin tubular structures without a GPU skeleton (Kirchhoff et al.)

**What it does**: L = CE + soft Dice + w x L_SR with L_SR = -(1/|C|) sum_c [sum_i Y_skel,i,c x P_i,c] / [sum_i Y_skel,i,c] (Eq. 1): a one-sided soft RECALL of the prediction on the "tubed skeleton" of the GT. The tubed skeleton is made once on the CPU per label (binarise, skimage thinning - Zhang-Suen in 2D, Lee in 3D -, dilate with a diamond kernel, multiply by the class mask for multi-class), so training needs no differentiable skeletonisation and no prediction-side skeleton. Weight w tested only at 0.1 and 1.0.

**Results that matter** (nnU-Net, Dice / clDice / beta0 error, % and counts, from the paper's tables): Roads (804 aerial images) CE+Dice 78.99 / 88.79 / 5.77, + clDice 79.15 / 89.00 / 6.54, + Skeleton Recall 79.25 / 89.06 / 4.85; DRIVE 5-fold 80.87 / 80.26 / 57.0 -> clDice 81.05 / 80.68 / 44.5 -> SR 80.99 / 80.83 / 38.75; Cracks about equal; ToothFairy 3D 71.80 -> 74.42 Dice (clDice 72.36); TopCoW 13 classes 85.36 -> 86.59 Dice while clDice runs out of memory on a 40 GB A100. HRNet DRIVE: Dice falls 80.34 -> 76.08 with SR while clDice rises 77.83 -> 84.20 (one counter-example). Cost, mean of the 5 binary datasets: clDice +88 % training time and +52 % VRAM, Skeleton Recall +8 % and +2 %.

**Transferable technique**: precompute the (tubed) skeleton in the GT cache next to the 0.5 m layers; term = 1 - sum(w x tube x p) / sum(w x tube) with the per-cell weight w already used for masks (undefined 0, occluded 0.5) and the registration weight w_reg. Differentiable, no argmax, no matching, no prediction-side op; soft predictions are native. Tube radius = 1 cell would make it a recall term close to our tolerant Dice's second half.

**Cost and fit**: near zero on the GPU; one skimage call per layer per frame at cache time. Known-answer test: p = GT gives 0; a gap of g cells in a straight line of N skeleton cells gives g/N. Does NOT address soft labels (skeleton needs a binary GT: threshold the coverage at 0.5) or ignore masks (weights are ours to add).

**Doubts**: gains over plain CE+Dice are tenths of a Dice point and ~15-30 % in beta0 on 2D roads / vessels; all datasets are wider structures than our 1-3 cell lines; the one-sided recall rewards over-thick predictions unless the Dice / BCE term holds precision (our tolerant Dice does); no registration-noise experiment; DRIVE and Cracks have no test set (5-fold only).
