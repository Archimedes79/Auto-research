**What it does** [checked]: surround-view sparse-query detector for a 152.4 m x 152.4 m range. A YOLOX-style anchor-free 2D head on the FPN gives 2D boxes (score >= 0.1 kept); each box centre gets a depth from a light depth net (classification over discretised bins) and is lifted to a 3D adaptive query (positional embedding of the 3D centre + semantic embedding of the sampled feature and the 2D score); these are concatenated with 644 learnable global queries. Perspective-aware aggregation: SE-enriched features, 3D deformable attention with learned offsets projected to several FPN levels and views. Range-modulated 3D denoising: negative query offsets grow with log(range), K = 2 negatives per group is best. FPN levels have strides 1/8, 1/16, 1/32, 1/64 (supplement cites p2-p5). Section 3.3 gives the reason for the high-resolution levels: "small distant objects require large-resolution features for precise localization". Inputs: Argoverse 2 960 x 640 with VoV-99, 1536 x 1536 with ViT-L; nuScenes R101 512 x 1408 (val), ViT-L 1536 x 1536 (test).

**Results that matter** [checked]: Argoverse 2 val, 26 classes, 150 m, same 960 x 640 / VoV-99 input: StreamPETR 20.3 mAP / 14.6 CDS, Sparse4Dv2 18.9 / 13.4, Far3D 24.4 / 18.1; with ViT-L at 1536 x 1536 31.6 / 23.9 (LiDAR CenterPoint 27.4 / 21.0 in the same table). Components (StreamPETR base 20.3): adaptive queries 22.4, + perspective-aware aggregation 23.4, + denoising 24.4. Table 7 (mAP %): training on 50 m instead of 150 m, Far3D scores 0-50 m 38.7 vs 37.7 (-1.0) and 50-150 m 1.9 vs 9.9 (+8.0), recall 50-150 m 4.6 vs 20.5; StreamPETR 50-150 m mAP 1.6 vs 7.4 (recall 4.2 vs 17.2). nuScenes val (R101, 512 x 1408, perspective pre-training): Far3D 51.0 mAP / 59.4 NDS against StreamPETR 50.4 / 59.2 and Sparse4Dv2 50.5 / 59.4, i.e. no gain in the 50 m regime. NOT in the paper (the summariser checked): ablation of input resolution, of the 2D detector, of depth supervision; FPS; compute numbers.

**Transferable technique**: (1) far recall is first a LABEL / TRAINING-RANGE and query problem: the same model gains +8 mAP at 50-150 m only by being trained with far labels, and a plain StreamPETR gains +5.8; check that our losses and GT cover 40-60 m with the same weight (a label-range check, free); (2) the authors state that distant objects need the high-resolution FPN levels (stride 8, with p2 as an option), the same reading as our stride-8 result (recall 0.81 vs 0.17); (3) teacher-forced depth: ground-truth depth builds the queries early in training, predicted depth takes over later (supplement) - a stability trick for any depth-weighted lift; (4) range-dependent noise scale (log) in the denoising negatives is a cheap range-aware loss design.

**Cost and fit**: heavy backbones in the headline numbers (VoV-99, ViT-L at 1536 x 1536), seven ring cameras, boxes not lanes; no nuScenes code. Only the choices above transfer.

**Doubts**: the source of the ground-truth depth is not stated on the page (LiDAR is mentioned only as a comparison baseline); no resolution ablation, so "stride 8 / high resolution" is the authors' design statement, not a measured effect; Argoverse 2 front-camera resolution not on the page; Table 7 is mAP over all classes with a tiny 50-150 m value (9.9), a noisy base; licence type unknown.
