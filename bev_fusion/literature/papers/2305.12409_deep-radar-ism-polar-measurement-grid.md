# 2305.12409 Deep radar inverse sensor models for dynamic occupancy grid maps (polar measurement grid from sparse detections)

| groups | A1: 3, A5: 1, A8: 2, F4: 3 |

| verdict | use (the closest published match to "sparse automotive radar detections to a learned polar footprint") |

**What it does**: Each sensor's single frame of sparse detections is binned into a binary polar map of A x R = 300 x 350 cells (0.36 deg, 0.2 m; a cell is 1 if it holds a valid detection; Doppler is not an input). A DANet (ResNet backbone, position and channel attention in the head) segments it into a polar measurement grid with three classes free / occupied / unknown, output as evidential masses (b_F, b_O, b_FO). The network is applied per sensor, so mounting position is not baked in. The polar grids are later resampled to a Cartesian 700 x 700 grid (0.2 m) for the dynamic grid map, and Doppler is copied into cells with b_O >= 0.196.

**Supervision**: lidar (VLS-128) measurement grids by ray tracing, fused over time into a lidar dynamic grid map; belief masses b_O = m_D + m_S + m_DS, b_F = m_F; moving objects as oriented boxes with b_O = 1; occupancy in the partially observed zone is removed where no radar detection exists. Loss: Dice (compared with Lovasz and weighted CE; occupied pixels are about 2 % of the annotations). Momentum SGD, lr 0.003, azimuth flip 50 %. Data: six Continental SRR 520, about 180 km training (56,568 images), 30 km test (12,180).

**Results that matter** (test, highway): mounting independence (mIoU, setup A to unseen setup B) front centre 68.70 to 63.52, front left 66.20 to 65.95. Two-frame aggregation 67.54 mIoU vs 65.77 for one frame (occupied 30.08 vs 27.4), not adopted. Against a Gaussian-mixture geometric ISM on a 1 deg x 0.5 m grid: P(occupied | true occupied) 38.68 vs 15.30 (percent), P(unknown | true free) 11.05 vs 36.13. No runtime reported.

**Transferable technique**: radar detections live on the sensor's own polar grid; a small image network turns the binary hit map into a learned range-azimuth footprint (free / occupied / unknown evidence), trained against lidar rays with an explicit "unknown" class. This is the learned replacement for a hand-set Gaussian: spread along the ray and across azimuth are decided by the data. Per-sensor application removes the mounting yaw from the model, as our per-sensor sigma points plan does.

**Cost and fit**: ResNet + attention on 300 x 350 inputs per radar; a few ms class (est). Needs lidar for the labels (we have it only in the 80 GB part we did not download), but the lidar could come from nuScenes keyframes only (2 Hz) since the target is static geometry.

**Doubts**: input is binary, so RCS and Doppler are thrown away; the "unknown" class is also the way the model hedges (class prior, not a calibrated spread); the baseline is a plain Gaussian mixture; no code or runtime; nuScenes not used (highway radar with 6 SRR 520).
