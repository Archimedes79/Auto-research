# 2608.29194 RLG-TPV: Doppler-guided temporal fusion (DGTF) with a velocity-gated warp

**What it does**: Camera-radar tri-perspective-view detector. The temporal block aligns past fused features with a motion field anchored on radar radial velocity: phi_j = s_j * Smooth(v_j) + psi([f_j, v_j]), a Doppler anchor (v_j: BEV motion map from "compensated radar velocity", Gaussian smoothed, learnable scale s_j) plus a learned residual psi for motion the sparse radar does not show. A gate phi_j <- phi_j * sigmoid((|Smooth(v_j)| - tau_v)/T) switches the correction off where the measured speed is below a threshold tau_v, so static cells get only the ego warp; an occupancy gate also suppresses cells with weak feature support. Four keyframes at 1 s spacing; the page does not say whether they are stacked or recurrent, nor how the ego-compensation of the Doppler is done.

**Results that matter** (nuScenes val): full model 0.4981 mAP / 0.5959 NDS; DGTF adds +0.0013 mAP and +0.0040 NDS over the previous configuration, which the authors themselves call within run noise (about +-0.005 mAP). One keyframe instead of four: mAP -11.5 %, NDS -18.8 % (temporal context in general, not DGTF). Headline: -30.7 % velocity error and -31.9 % orientation error vs published CRN. No mAVE in the DGTF ablation; no latency, parameter or memory figure.

**Transferable technique**: the gate form (sigmoid of speed minus threshold) as a way to apply the moving-object warp only where radar says something moves, and to leave static content with a plain ego warp. A static/moving split without a classifier.

**Cost and fit**: Fits camera + radar; the temporal block is a small conv/warp. Cost not reported.

**Doubts**: Gain inside noise; ego compensation of the Doppler unspecified; single-source result, no code; a 2026 preprint without review.
