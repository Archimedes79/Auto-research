**What it does**: Forward projection (LSS, depth head, pooled to BEV) produces a sparse BEV. A foreground-region proposal network (3 x 3 conv + sigmoid, threshold 0.4) selects the empty or uncertain BEV cells; for those, a backward pass (BEVFormer-style spatial cross-attention) pulls image features with N_ref = 4 heights in [-5, 3] m. The backward pass is made depth-aware: the depth of each 3D reference point is linearly interpolated between the two adjacent bins of the pixel's predicted depth distribution (118 bins, d0 = 1 m, step 0.5 m) and dotted with it, w_c = w_i w_i' + w_{i+1} w_{i+1}' (Eq. 2); the attention output of that point is multiplied by w_c (Eq. 4). The result is added residually to the forward BEV. Depth enters as a scalar weight per sampled point: the whole distribution is kept in the depth net, but the weight is a single probability, and the module sits in a deformable-attention layer, not a plain gather.

**Results that matter** (nuScenes val, detection): depth-aware vs not: BEVFormer 0.379 -> 0.387 NDS, BEVFormer-T 0.461 -> 0.472, FB-BEV 0.397 -> 0.406, FB-BEV temporal + depth 0.489 -> 0.498. Forward 0.382 / backward 0.379 / both 0.406 NDS (no temporal, no depth supervision). View-transform latency FB-BEV 2.6 / 3.4 / 6.6 ms at BEV 128 / 256 / 400 against BEVDet 0.7 / 0.8 / 1.5 ms; without the region proposal 3.4 ms instead of 2.6. GPU not named; no end-to-end FPS. Test 62.4 NDS. 58.4 M parameters, 192 GFLOPs (no temporal). No map segmentation.

**Transferable technique**: the interpolated-bin dot product (Eq. 2) is the exact way to evaluate p(z_cam | u, v) at a fractional depth; two points on one ray (5 m and 25 m) get different weights. Also the argument that backward pulls create false positives along the ray, which the depth weight removes. A gate that skips empty cells (region proposal) cuts VTM time by 0.8 ms at 128 x 128.

**Cost and fit**: needs deformable attention and a depth net; the VTM is cheap but the paper never reports the whole-pipeline speed. NC licence rules out copying code.

**Doubts**: gain from the depth weight is +0.8 to +1.1 NDS only; GPU not named; the weighting sits inside the attention so the plain-gather cost is unknown; all numbers are 3D detection, not map layers.
