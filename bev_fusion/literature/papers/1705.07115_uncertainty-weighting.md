# 1705.07115 Multi-task learning using uncertainty to weigh losses (Kendall et al.)

**What it does**: Each task gets a learned homoscedastic noise parameter sigma_i. Memory: L = sum_i (1/(2 sigma_i^2)) L_i + log sigma_i (a regression form; classification uses a factor of 1/sigma^2 and a different log term), usually parameterised as s_i = log sigma_i^2 for stability. Trained jointly for depth regression and semantic and instance segmentation from one image.

**Results that matter**: the abstract claims a jointly trained model with learned weights outperforms separately trained single-task models. No numbers on the page.

**Transferable technique**: add one scalar per head to the optimiser; no extra backward pass. Pair with GradNorm as the second choice when weights collapse. Clamp s_i to a range to avoid starving the thin-lane head.

**Cost and fit**: free. Risk for us: the focal/Dice terms of a lane head and the L1 terms of box regression are not likelihoods, so the "1/(2 sigma^2)" interpretation is loose.

**Doubts**: tendency to down-weight the hard, noisy task (the thin lane class) because its loss stays high; no result on BEV tasks on the page.
