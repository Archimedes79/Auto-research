**What it does**: L_B = sum_q phi_G(q) s_theta(q), phi_G = signed distance to the GT boundary (negative inside, positive outside), s_theta the softmax / sigmoid output. It is a linear function of the prediction (approximates a one-sided L2 contour distance, Dist(dG, dS) ~ 2 integral over S minus G of D_G), so the weight map is computed once from the GT. Total (1-a) L_regional + a L_B with a raised from 0.01 by 0.01 per epoch ("rebalance"), because L_B alone collapses to empty foreground.

**Results that matter** (validation, mean of 3 runs, DSC / HD95 mm): ISLES GDL 0.511 / 5.32 -> GDL + boundary (2D) 0.644 / 4.80, (3D) 0.659 / 2.73; WMH GDL 0.768 / 3.63 -> 0.793 / 2.04 (2D), 0.818 / 1.70 (3D). With cross-entropy the gain is mixed (ISLES DSC 0.608 -> 0.631 but HD95 4.57 -> 5.96; WMH DSC 0.757 -> 0.756, HD95 4.36 -> 2.89). Table 2: negligible extra training time; the Hausdorff-loss baseline needs the distance maps recomputed every epoch.

**Transferable technique**: for a line layer use phi = d(c) - r0 with d our truncated unsigned distance in metres (r0 = half a cell so that the line cells are negative): L_B = sum(w x phi x p) / sum(w). A false positive 2 m from a divider costs 4x one at 0.5 m, so the 0.5-1 m registration offset of the map costs little (graded tolerance instead of the dilated Dice's hard 1-cell step) while spurious lines far away are punished. Soft labels: phi comes from the geometry (0.5 level set of the coverage), the prediction may be anything in [0, 1]; ignore masks: multiply by the cell weight (w = 0 gives exactly zero gradient). Spec test: p = one-hot at distance d from the GT line gives L_B = d - r0; p = GT gives -r0 x (line cells); gradient is phi itself.

**Cost and fit**: zero extra GT (we store the field), one multiply-add per cell on the GPU. Needs a regional term next to it (our tolerant Dice) and the alpha ramp; can be negative, which does not play well with a Kendall term exp(-s) L + s unless L_B stays inside the line group at a fixed ratio.

**Doubts**: only binary medical tasks, two datasets, no augmentation, 3 runs; cross-entropy + boundary was unstable in places; no thin (1-3 pixel) structures, no registration-noise test; with soft sigmoid output it can still push probability mass to be diffuse inside the near zone.
