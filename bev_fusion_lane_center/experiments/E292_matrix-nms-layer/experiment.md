## 3. Cost, stated before the run
- **Parameters and flops of the layer:** 0 parameters; per frame 8 shifted neighbour passes over the 50 x 50 node grid with about 28 element-wise operations each, about 0.6 MFLOP (counted by hand from `qmnms.py`; no matrix product, so no MAC count in the FlopCounter sense), against 7.96 GMACs for the E312 system and about 4.7 GMACs of B's pyramid: below 0.01 % of the compute.
- **Time:** on the CPU (torch, one thread, 1 x 50 x 50) the layer took 2.98 ms in the first run and 1.48 ms in the critic's rerun, the hard step it replaces (`qgraph_readout.apply`, numpy, python loop, mean over 200 frames of B's dump) 1.80 ms and 1.47 ms: **on the CPU the layer and the hard step are equal within load noise**; CPU torch time is not the GPU cost. On the GPU the layer is about 100 small kernels in the 24.2 ms of B and removes a host-side python step; neither is measured (no idle GPU while day13 trains): the paired timing of the cost condition above is part of the card.
- **Budget:** four fine-tune runs (a and c2, two seeds) of about 40 minutes, four B-dumps of about 5 GPU minutes, the paired timing, CPU scoring of about 8 minutes per read-out: about 3.5 GPU hours in two slots (about 2 hours of wall time).
