**What it does** [checked]: replaces the ResNet-101 of Simple-BEV (bilinear-sampling lift, six cameras, 200 x 200 BEV) by DINOv2 ViT-B / ViT-L adapted with LoRA (rank 32 on the query and value projections of all attention layers; rank 64 was 0.1 lower), about 1M (ViT-B) and 3M (ViT-L) trainable parameters plus about 5M decoder; robustness is measured on nuScenes-C. The comparison table varies input size and feature-grid size together.

**Results that matter** [checked, nuScenes val, 28,130 train / 6,019 val instances]:

| exp | model | input | feature grid | IoU |
|---|---|---|---|---|
| A | Simple-BEV, ResNet-101 (stride 8) | 224 x 400 | 28 x 50 | 42.3 |
| B | Simple-BEV, ResNet-101 (stride 8) | 448 x 800 | 56 x 100 | 47.4 |
| C | DINOv2 ViT-B + LoRA (stride 14) | 224 x 392 | 16 x 28 | 42.3 |
| D | DINOv2 ViT-L + LoRA | 224 x 392 | 16 x 28 | 43.4 |
| F | DINOv2 ViT-L + LoRA | 392 x 700 | 28 x 50 | 47.6 |
| G | DINOv2 ViT-L + LoRA | 448 x 784 | 32 x 56 | 47.7 |

Frozen ViT-B 34.3, full fine-tune ViT-B 41.5, LoRA ViT-B 42.3 (Table 2); ResNet-101 has 37M parameters (42.3). No latency or FPS is reported.

**Transferable technique**: (1) input size is the lever in this family: doubling both image sides gains +5.1 (R101, A to B) with the same lift; the gain does not come from a finer stride (it stays 8), so it is "more pixels per object" through the whole backbone. (2) A stride-14 transformer at 392 x 700 (28 x 50 cells) matches a stride-8 CNN at 448 x 800 (56 x 100 cells), 47.6 vs 47.4, with four times fewer feature cells: the number of feature cells is not what limits vehicle IoU. That is for vehicles; thin lanes need the cell size on the ground to be below the line spacing, which is our own finding at stride 16 and not tested here. (3) A frozen or LoRA foundation encoder is competitive in accuracy (ViT-L 43.4 vs R101 42.3 at the small size) but a ViT-L is far outside a 3060 batch-1 budget; the table gives no ViT-S point.

**Cost and fit**: not a fast encoder: ViT-L is 300M parameters (from memory); the value for us is the evidence in rows A / B / F / G, and the confirmation that stride 8 at 2x resolution reaches the same level as a much coarser grid of a stronger backbone.

**Doubts**: vehicle class only (inferred), six cameras, no lanes, no latency; rows are not one-factor ablations (backbone, input and grid change together); no code on the page; a DINOv2 ViT-S point is missing (the earlier collected note 2501.08118 has the same gap).
