**What it does**: 2D CNN -> interpolation into a 256x256x16 voxel grid -> 3D CNN -> per-voxel occupancy probability (sigmoid), rendered to depth for supervision. Supervised loss: SILog depth (lambda 0.85, alpha 10), BCE and L1 on sampled points; self-supervised nuScenes variant: photometric loss (beta 0.85) with SDF values converted to density before rendering. BCE + Dice gave no gain.

**Results that matter** (DDAD supervised, discrete depth Abs Rel / RMSE): full 0.206 / 9.353; depth loss only 0.208 / 9.510; BCE only 0.221 / 10.283; L1 only 0.225 / 10.461; no ImageNet pretraining 0.265; SurroundOcc reference 0.209. Self-supervised nuScenes: SDF 0.203 / 7.534 against density 0.226 / 7.876. Timing on A100: about 230 ms total (2D CNN 31, interpolation 3, 3D CNN 101, rendering 95); rendering can be skipped for occupancy-only output; SurroundOcc 305 ms.

**Transferable technique**: rendering is ~40 % of the cost, and not needed at inference; the depth-only SILog rendering loss gives almost all the gain over classification losses. SDF over density: Abs Rel 0.203 vs 0.226 (-10 %) for self-supervision.

**Cost and fit**: simple and small, but still a 3D CNN (101 ms) which the FlashOcc reshape would avoid.

**Doubts**: no occupancy IoU / mIoU for its own model; depth metric as a proxy for occupancy; SDF vs density only for the self-supervised nuScenes case.
